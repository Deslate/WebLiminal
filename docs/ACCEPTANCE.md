# v1.7 验收：施工模数、内弧、阳角

2026-09-27；Apple M3 Max / Chrome 153 / WebGPU Metal。证据根目录 `/Users/steven/Projects/workroom-v1.7-evidence/final/`。旧验收完整保存在 [v1.6](ACCEPTANCE-v1.6.md)。详细尺寸、材质与近似见 [PHYSICS.md](PHYSICS.md)。

## 六条逐项

1. **模数**：墙、柱、池底统一250mm，y=0为水平基准；共面砖跨越不同几何块时共用砖号和噪声种子。取消随机挪动缝中心、旋转整砖的做法，保留砖面高度和釉面变化。内弧厚度方向也改为世界z基准，不再从各拱的局部零点另起铺。前排起拱线提高5cm至2.50m，与后排和皮数一致。
2. **拱内弧**：半圆32等分，左右对称，顶缝居中。正背两侧砖圈的放射缝接入内弧；外圈显式切缝与普通墙面方砖分开。不是把方格拉伸到圆弧上。
3. **柱角收口**：最终采用45°对缝切，两个面使用同一切平面；水平槽底继续绕角相接。内弧与端面的外缘也作同样的切面处理。早期L形收边方案已弃用，不把旧轮次图当作最终交付。
4. **规格有理由**：250mm是普通砖及坯料规格；拱上较窄的楔片是按半径裁切，前排约175–199mm、后排206–231mm的内外弧长，加上缝隙能落在250mm坯料内。0.8m洞口深度采用150/250/250/150mm的对称模数裁切。
5. **30cm细节**：墙面、内弧、柱角均实际渲染并检查。凹槽、砖面高差、圆角和切面参与主射线求交和局部遮挡；不是仅把缝画深。但仍是局部高度场，非独立封闭砖体，极端掠射角和次级反射的毫米级遮挡有近似。重机位运行时会动态降低分辨率，这项清晰度折扣没有用固定分辨率证据图掩盖，详见下面的实际运行数据。
6. **亮点与锯齿**：边缘自适应阈值收紧，反差边缘使用8样本；没有重写v1.6单像反射方向或引入历史滤波。未彻底解决所有白柱单像素边缘和釉面高反差倒影的空间走样，不宣称“零锯齿”。水面的固定错位副轮廓修复保留。

## 测量方法与预算取舍

性能均为GPU完成帧间隔，独立于截图、录像；不是RAF或视频编码帧率。普通静止窗口5–17秒、行走窗口20–22秒。近景每个状态运行11秒，统计末尾180个完成帧，报告实际内部尺寸与最低一秒fps。近景成绩是适应负载后的稳态，进入重机位时的短暂降帧不能由这些数字排除。

光照预算未减少。相机由全局4/8样本改为不透明平坦区2样本、水面4样本、反差边缘8样本；属于公开的空间求积取舍。另加完整砖面平面求交、远离缝的遮挡快速判断。动态分辨率检查从4秒缩短至0.9秒，并增加离开重机位后的恢复；只换内部计算尺寸，不重复清空屏幕画布，不混合历史帧。

普通场景最终：静止59.86fps，最低一秒59.44、p95 18.7ms；行走60.06fps，最低一秒59.99、p95 18.5ms。全程1280×832，首帧526ms，两个计时窗口>50ms帧均为0。记录在 `performance/performance-headless.json` 与同目录完整帧日志。

## 连续画面、回归及保留问题

`tile-construction-motion.webm` 是实际浏览器录像，19.48秒、487帧、编码25fps，含16秒连续视角运动，正常胶片颗粒。路线从柱角推进到30cm，再沿内弧抬高检查。录像期间内部尺寸960×624至1280×832，结束恢复到1192×776；录像含编码开销，不能当作上面的独立性能成绩。已检查全程概览接触表、柱角连续帧与亮点候选放大图，未见成片采样噪点或内部尺寸切换造成的空白闪屏。

另在 `synchrony/` 保存六组各61帧、步长1/60秒的无颗粒PNG，共366帧（墙面、暗处、低视角倒影、釉面、内弧、柱角）。后三类近景连续表及低视角回归用来检查接缝、反射随移动的变化。这是可控逐帧验证，不是实际60fps录屏。六组水/焦散/间接光时间轴一致，跳到别的相位再返回均逐字节相同；30Hz和60Hz停下质量提升均在0.80秒完成。366帧的孤立亮点启发式计数均为0，这不代表全部空间走样已经消失。

真实录像的同类启发式在排除UI后，有13帧检出1–2个孤立亮点候选（每帧最大2）。已查看第80帧候选放大图，位于白柱明暗轮廓，边缘仍有像素阶梯。因此**第六条仅改善、未根治**；釉面高反差倒影也仍有空间锯齿，不能称为随机光追噪声，但确实是留下的画质问题。原始录像、逐帧PNG、`video-analysis.json` 和 `video-review/` 均保留，未通过改图抹掉问题。
