# v1.6 验收记录

2026-09-27，Apple M3 Max（30 核 GPU）、Chrome 153 / WebGPU Metal。旧实现为 1f84a62，历史结果保存在 [v1.5 归档](ACCEPTANCE-v1.5.md)。证据根目录 `/Users/steven/Projects/workroom-v1.6-evidence/`。本次没有配置或推送远端。

## 五条结论

1. **固定副轮廓消除**：每个空间子样本沿真实微法线的单一反射方向追踪，去掉四个固定锥角点造成的多幅像叠加。水面和釉面均改。保留 4/8 个确定性像素子样本，新增只作用于反射分量、约一像素宽的连续空间重建。不是简单把锥参数设零，也不模糊整幅画面。白柱同机位、同相位对比中，固定偏移的第二道轮廓消失，真实水波扭曲与瓷砖细节仍在。
2. **运动稳定**：244 张受控连续帧与 19.44 秒真实录屏已检查。受控帧亮点指标为 0，未观察到成片采样噪声、固定副像或新增可见闪烁。录像检出一处实体白柱边缘的单像素亮点，详见下文；不能写成所有像素绝对无走样。胶片颗粒 .004 保留，水面/反射/焦散同一连续时间轴，没有历史图像混合。
3. **性能通过**：普通静止/行走 58.77/59.81fps；30cm 正对墙面 53.90/53.81fps，保持 1280×832。下面列出完整时间分位与独立重测基线。没有降低光子预算、近景材质、相机样本或分辨率。
4. **证据齐全**：低视角白柱修前/修后、釉面修前/修后、含移动的实时 WebM、60Hz 连续 PNG、相位和时间轴记录均在仓库外，路径见下文。加入性能优化之前的生产构建与第二轮三机位图逐字节一致；最终优化的舍入差异另作严格像素比较。
5. **取舍公开**：不需要在固定副像和随机闪烁之间二选一。代价是新增 48.75MiB 反射中间缓冲及两遍空间重建。重建是有宽度上限的屏幕空间近似，不是严格粗糙 BRDF 积分；非常细的反射纹理略有衰减，宽粗糙度反射可能偏清晰。有限像素、4/8 样本及一层釉面反射仍有局限，详见 [物理说明](PHYSICS.md)。

## 独立 GPU 完成帧性能

视口 1512×982，内部分辨率全程 1280×832。顺序执行，无同时录像、截图任务或另一项 GPU 测试。完成时间来自 `queue.onSubmittedWorkDone()`，包含调度等待；不是 RAF 数或视频编码帧率。

| 测试 | 平均 fps | 最低一秒 fps | p95 帧间隔 |

| 未修改 v1.5，本轮行走重测 | 59.96 | 59.92 | 18.6ms |
| v1.6 最终静止 | 58.77 | 57.52 | 18.9ms |

v1.6 最终构建首帧 **361.1ms**（本版较早一轮532.7ms，旧版本轮524.9ms；不是清空驱动缓存后的冷启动承诺）。静止最大间隔21.0ms、行走19.3ms，两个窗口中 >50ms 帧为 0。移动均值相对旧版重测低约0.24%，不能声称没有任何成本。旧版上轮 49.25/51.07fps、本轮 59.77/59.96fps，支持当时存在并行负载污染的解释，但无法仅凭重测确定唯一原因。

近景性能记录取各阶段末尾 90 帧；最低完整一秒均值可能略高于整个短窗口均值。另对低视角倒影与30cm斜视釉面做更长的独立测试，取末尾180帧：

| 白柱低视角倒影 | 59.88 / 59.74 | 59.63 / 59.70 | 18.5 / 18.6ms |

## 证据及检查方法

- `before/low-default.png`、`final/comparison/low-default.png`：修前/修后原图；相机 `(2.35,.92,5)`，yaw=0、pitch=.025，时间输入12，grain=0。原版本在改代码前实拍，未后期修图。
- `final/reflection-before-after.png`：上述两图相同区域并排裁切，左旧右新。左侧白柱倒影边缘121行的10%→90%亮度过渡宽度，中位数从30显示像素降到3像素；方法、范围及极值保存在 `edge-profile.json`。此指标包含真实波纹和砖缝，不能单独证明物理正确性。
- `before/glaze-default.png`、`final/comparison/glaze-default.png`：30cm斜视釉面同机位对比。`zero` 与 `unfiltered` 文件为额外诊断控制，默认交付不是关闭过滤。
- `round-1/` 保留过宽过滤的失败轮次；检查后把水面/釉面标准差上限由4像素收紧为0.8/1.1像素。`round-2/` 是随后通过视觉检查的版本。`final/build-equivalence.json` 验证性能优化前的构建与第二轮的三机位图完全一致。最终性能优化的244帧逐字节比较没有通过；进一步检查，所有通道的最大差异仅1/255，每帧绝大多数像素完全一致，最大通道平均误差约1.52e-6（0..255）。这是舍入级差异，不能称“逐字节相同”。`final/optimized/synchrony/equivalence-difference.json` 与 `scripts/compare-v16.py` 保存严格阈值检查：单通道≤1，整帧平均<0.00001。录像在此算术优化之前录制，最终连续帧与录像对应实现经上述误差界限核验。
- `final/reflection-motion.webm`：**19.44秒、486帧、25fps** 的真实浏览器录屏，包含16秒演示：低视角观察白柱倒影、平移转头、走近釉面并继续转头。其余为进入/结束画面。没有冻结水、加速播放或历史累积。25fps是编码频率，不是渲染性能。
- `final/recording.json`：160个实时状态样本，位置全部有效，始终1280×832，水/焦散/漫反射时间完全相等，无控制台或GPU错误。
- `final/video-frames/`、`video-review/`、`video-analysis.json`：全部486帧解码、自动亮点检测、连续联系表及全片时间概览。人工检查了全片概览、倒影/釉面连续页与原尺寸连续裁片，未把“看过概览”写成每张原图都逐像素看过。场景检测仅在第3秒后运行，并屏蔽UI；第314帧 (601,251) 检出一个亮点，放大复核在实体白柱明暗边界，非倒影副像或随机火花。放大图 `pixel-review-251-601.png` 保留。其余有效帧未检出。检测阈值在JSON中；指标不能替代视觉判断。
- `final/synchrony/` 及最终 `final/optimized/synchrony/`：明墙、暗墙、低视角倒影、30cm釉面各61张、间隔1/60秒。后两组同时平移和转头。全部图像不同，每组跳到其他相位再返回同相位均逐字节相同。孤立亮点最大计数均为0。相邻帧亮度MAE（0..255）中位数分别0.423、0.173、1.011、1.059；包含真实运动，不能直接等同噪声。30Hz/60Hz停止测试均在0.8秒达到最终质量权重。
- `baseline/performance-headless.json` 与 `final/optimized/performance-headless.json`：未改版与最终修后普通场景独立帧率、完整帧日志。`final/optimized/near.json`：最终贴墙性能及材质证据。`final/proof/`：改水位、改开口、恢复原状以及独立光路核验；恢复图哈希一致。`final/reference/`：256批背景参考，仅用于有限模型回归，不是无偏真值。
