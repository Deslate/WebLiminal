## 六条

1. 删除正背外墙的放射砖圈、拱腿饰面带及其外边界切缝；墙面统一250mm方格，洞口直接裁断墙砖。
2. 弧形排砖仅在洞口内表面和两条直线侧厚度面使用，其他面未新增处理。
3. 外墙从相邻区域到洞口边缘使用同一平面网格，不存在离洞口250mm的第二条轮廓。只看外表面是普通切砖墙；内侧在正面图中可见是墙厚，不是附加镶边。
4. 内侧展开坐标、250mm整模数、起拱线对应和拱顶对称合缝保留，未改`archCourse`及`archAlong`。
5. 没有增加场景对象、材质、造型或照明。运行时代码净删除，只有原有洞口毫米级切边从已删除的饰面模式归并到普通墙面分支。
6. 零位图部署资源；所有截图在仓库外。

## 保留限制

局部高度场不是每块砖的完整封闭几何，曲面使用局部切向近似，次级反射未解析所有毫米级遮挡。原有釉面空间锯齿和轮廓亮点未根治。本版未改任何性能降级策略，不把这些问题混入此次去镶边工作。

## 回归与性能

内侧两个排砖函数与ac63186源码逐字相同。GPU执行排砖核验160点，中心最大误差2.314e-7m，宽度误差4.351e-8m。三张内侧修前/后图平均RGB绝对差为0.020–0.065/255；并非逐字节完全相同，外墙反射与编译浮点变化仍可影响画面，不能据此声称所有光传输完全不变。已查看同机位对比与12秒内侧沿缝序列的全程概览、起拱线相邻帧。原始301帧在`inside-frames/`，是时间步证据，不是实时帧率测量。

性能独立于截图与录屏，统计GPU完成帧。普通静止窗口5–17秒，行走20–22秒；近景每状态11秒，取末180帧。M3 Max / Chrome153，首帧584ms；普通静止59.97fps、行走60.08fps，内部1280×832，p95分别18.9/19.0ms，两个窗口均无>50ms帧。

最终检查：10项单元测试、生产构建、零位图检查通过。六组共366帧完成同相位复现与光照同步检查，30Hz/60Hz停止细化均0.80秒完成，浏览器错误为空。孤立亮点启发式每组最大值：{'wall': 0, 'dark': 0, 'low': 0, 'glaze': 0, 'arch': 0, 'corner': 1}。这只是像素检查，不等于所有轮廓锯齿都消失。水位/天窗/平波/恢复控制、256批参考均生成成功，光学CPU对照误差约3e-7以内。

额外实时录像回归保存在`regression-video/`，160次状态采样、浏览器错误0、首帧524ms；录制期间还有并发应用和CPU图像分析，最终内部尺寸792×512，不把录像尺寸或编码帧率当作独立性能成绩。交付近照均来自固定1280×832渲染。
