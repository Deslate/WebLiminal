2026-09-27；Apple M3 Max（30 核 GPU）、Chrome 153 / WebGPU Metal。上一版记录见 [v1.4](ACCEPTANCE-v1.4.md)。证据根目录：`/Users/steven/Projects/workroom-v1.5-evidence/final/`。生产构建在 `http://127.0.0.1:4174/poolrooms/` 验证；开发服务保持 `http://127.0.0.1:4173/`。

## 四条要求

1. **连续光斑**：删除 0.4 秒关键帧及其插值。当前水面产生直接焦散，再传播当帧漫反射变化。明墙、暗墙各采 61 张、间隔 1/60 秒，全部图像不同；同一相位从任意前序相位返回，PNG 哈希完全相同。没有相机历史或光照历史滤波。人工检查中光斑连续爬动、聚散，未见原来的关键帧台阶。
2. **同一时间轴**：全部受控帧及实时记录中 `waveTime == causticTime == diffuseTime`；相机几何、反射及发光路径共享同一个 uniform 时间。GPU 实际光路与独立 CPU 重算一致：Snell 最大残差约 2.1e-7、水面高度约 8.1e-8m、法线约 2.8e-7；两种介质分支都核验。
3. **噪声及性能**：下表独立测量 GPU 完成帧，没有同时录像或另一项 GPU 验证。真实录像逐帧解码作自动检查，541 帧中场景孤立亮点检测为 0。人工检查连续页、整段时间概览和原尺寸关键帧，没有观察到新增采样闪烁。此结论覆盖已测路线、相位和默认水波，不是所有设备/水位/开口/掠射角的保证。胶片颗粒仍为 .004。停止细化在 30Hz、60Hz 时间步下均于 0.8 秒达到最终权重。
4. **预算公开**：平均水面背景仍用 49152×128 条路径，初始化一次；每显示帧另算 278528 个水光包、两个 Fresnel 分支，32 方向/探针、四轮当前时刻漫反射变化传播。没有继续降低光子批大小、材质、相机样本或默认分辨率。动态间接光采用平均水面的线性近似，详见 [物理说明](PHYSICS.md)。

首帧 **1102.2ms**；最终普通静止/行走窗口中超过 50ms 的帧均为 0。行走平均相对同环境旧版低约 **0.94%**，不能宣称零差异，但未观察到明显退化。历史 58.8/59.0fps 本轮没有复现，不能冒称仍为 60fps。

帧间隔来自 `queue.onSubmittedWorkDone()` 后的实际完成时间，包含调度等待；近景最低一秒值是连续一秒窗口，整体均值可能略低于某个完整窗口。不是 RAF 次数、步进截图速度或录像编码 fps。原负载自适应分辨率未删除；最终以上窗口与整段普通测试均未触发分辨率下降。

中间版本贴墙曾低至约 26fps，未作为合格版交付。处理：把重复光照合成移到世界格；移动时复用静止档 64 点天光积分；传输链接改为按方向连续排列，减少 GPU 大步长访存。最后一项优化使普通行走由约 41fps 回到 51fps，且明/暗墙各 61 帧 **PNG 逐字节完全相同**。不减少方向、光包或传播次数。

## 证据与复现

- `wall-caustics-continuous.webm`：**21.64 秒、541 帧、25fps** 的真实浏览器录制，含 16 秒演示（前 8 秒固定盯墙，随后平移、转头、停止），其余是进入/结束画面。包含正常胶片颗粒；没有冻结水波，没有加速播放。录像编码帧率不作为性能成绩。
- `recording.json`：160 个实时状态样本，全部位置有效、无控制台/GPU 错误；实际渲染分辨率 1280×832。
- `video-frames/`、`video-review/`、`video-analysis.json`：完整逐帧解码、连续联系表、整段概览、逐帧亮度及孤立亮点指标。人工查看了第一轮全部连续联系表，最终轮整段概览、移动/停止及暗处连续页，并复核近景原尺寸图；自动指标检查全部最终帧。孤立亮点阈值和 UI 排除区写在 JSON 中，不能将“0 个孤立亮点”等同于数学证明无任何闪烁。
- `synchrony/`：明/暗墙各 61 张 60Hz 相位 PNG。明墙相邻帧亮度 MAE（0..255）0.394–0.453，中位 0.422；暗墙 0.159–0.195，中位 0.173。没有 24 帧停住再跳一次的模式。二阶差分和逐帧值在 `analysis.json`，真实运动也计入这些差分。
- `layout-equivalence/synchrony.json`：最终存储排列与录像/相位序列版本的 122 张同相位图逐字节相同；CPU 光路审计、相位历史独立、30/60Hz 停止期限再次通过。录像拍摄后仅变更了这项结果等价的存储排列。
- `performance-transposed/`：最终构建完整帧日志和性能报告。旧版对照在证据根目录的上一层 `baseline-v14-current-performance/`，从 e27c3e9 独立导出构建，同机顺序执行。
- `near-transposed/`：贴墙、斜视反射、柱体图及独立近景性能。
- `proof/`：原状、改水位、改天窗、近乎平水控制、恢复原状；恢复图哈希一致，GPU 光路核验通过。`reference/` 保存 256 批背景参考，仍是有限核模型，不能当作无偏真值。

## 尚有折扣

实时动态间接光是有限方向、平均水面附近的近似；太阳水光使用中央方向，水面天光只有四点面积求积，细于世界空间核的焦散仍会损失。这些是空间/光传输精度限制，不是时间插值。

釉面倒影亮边的锯齿、云状发虚和分层来自相机有限反射锥，与旧光照关键帧不是同一原因，本版明确保留。新出现的 BRIEF v1.6 编辑不属于本次 v1.5 实施，保留用户工作树修改，没有将它混入本次提交。
