# v1.16 验证记录

证据根目录：`/Users/steven/Projects/workroom-v1.16-evidence/final/`。测试环境：Apple M3 Max、Chrome 153 headless、WebGPU Metal；内部画面 1280×832。数据来自实际 GPU 完成帧，不是 RAF 次数。其他 GPU 验证结束后单独跑性能。

## 六条结论

1. **V 形尾迹：快走达到，慢走有折扣。** 用有状态有限水深色散方程，移动的紧支撑近似压力分布产生波面响应，没有画 V 形纹理或预设两条波臂。高角度录像中快走两条波臂斜向后延伸；慢走响应明显较弱，仍有横向波分量，不能声称所有速度都只有清晰 V。未硬锁深水极限的 19.5°，角度随水深和速度变化。
2. **弓形浪、侧脊：达到。** 隔离身体压力、关闭环境波测量，同一位置慢走弓浪峰值 54.6mm，快走 130.0mm。压力中心按速度前移，避免弓浪躲在圆柱后方。站立保留约 30mm 局部隆起。
3. **身后凹陷与合拢：达到；真实尾涡未做。** 快走后方最低 -78.0mm，慢走 -7.4mm。没有水平旋转速度场，不能称为涡量模拟。停止后解继续传播而非立即清空。
4. **速度与消散：达到。** 水中普通行走 0.8m/s，Shift 1.6m/s。身体后方 1–4m 的高度 RMS：慢走 1.29mm、快走 20.75mm。快走停止后 2/4/6 秒为 9.36/1.92/0.83mm（隔离实验）。脚步仍单独向原有细波场注入。
5. **性能、稳定、零位图：测试范围通过，有像素级例外。** 下表未降分辨率、光子预算或胶片颗粒。观看了快慢行走共 377 张连续原始帧、第一人称明暗移动 122 帧、两段 20 秒的每秒总览，并查看原尺寸关键帧与编码后帧。未观察到成片采样噪点、跳帧式水形变化或连续闪烁。1324 帧启发式扫描找到慢走 frame-0249 的一个孤立亮像素，位于圆柱与水面交界（887,424）；放大确认是边缘采样残留，不宣称像素级绝对无闪点。胶片颗粒保留。零位图构建检查通过。
6. **录像和慢快对照：交付。** 同机位俯角约 69°，每段 601 帧、30Hz、20.03 秒，覆盖站立、行走和停步消散。高码率视频是确定性物理时间回放，不是实时性能证明；另存真实键盘操作录屏。

## 没做到与未覆盖

身体波是线性色散软压力响应，与非线性背景场叠加，尚未双向非线性耦合；不是真实刚体排水边界，也没有尾涡脱落。身体谱场未实现内部墙、柱的反射，可能跨障碍传播；外部扩展域用吸收带抑制周期回绕。未验证任意设备、所有转弯路径、贴墙绕柱的尾迹正确性。慢走的 V 不及快走清楚，横向分量仍在。完整公式与近似见 PHYSICS.md。
