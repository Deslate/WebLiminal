# v1.22 池底接收重建与平静水体

任务接手于 v1.20 HEAD `c1fb6ca`，保留未提交 v1.21 的干净池底材质、Fresnel/Snell/吸收、天光去点阵采样与太阳分量分离。没有改变曝光、太阳辐照度、墙面材质、水面 BRDF、反射方向或镜头。开发期间 BRIEF 追加的 v1.23 光传输约束也遵守：下面是第一接收面的光通量重建，不是特效、预设图案或后处理叠光。

## 接收端

`solar-atlas.wgsl` 把水面参数域的微小三角形作为光束截面。每帧读取与相机、墙面光子相同的有状态水面，计算太阳入射、遮挡、Snell 折射、Fresnel 透射、水中吸收和池底接收。光束落点组成接收三角形，其携带功率除以接收面积成为辐照度；折叠处加和。

源网格 384×384，有限太阳圆盘采用三个固定等权方向；每帧 444675 个端点、884736 个三角形。片内密度依据邻近落点 Jacobian 插值，并归一化，使每个三角形的积分仍等于它携带的功率。不是为制造亮线调整增益。栅格使用 4×MSAA、RGBA16Float；每帧清空，无图像历史。2048² 接收图围绕天窗投影，默认像素尺寸 3.125×3.613mm。

相机在真实池底世界落点重建这份辐照度，再执行原有瓷砖 BRDF、水中回程吸收和色调映射。池底旧太阳辐照度从相机的粗照度场扣除，避免重复计光；旧光子结果继续供间接反弹。墙面、天空光、间接光仍在原接收系统中。接收图完全由运行时光路生成，没有位图输入、部署资源或屏幕空间光斑。

旧池底接收格实际为 2.083cm（不是技术背景描述中的4.17cm），其他部分仍用原格。只提升池底太阳分量；没有把整场景照度格扩大到毫米级。

## 平静参数

- 背景幅度从接手的0.12回到0.052；默认背景与脚步波场按0.28倍时间推进，仍由固定步长 PDE 逐帧积分，从 reset 回放。光子和相机每帧读取同一结果，没有冻结水或错开照明更新。
- 这是为平静观感采用的时间尺度标定，**不是声称真实重力波传播速度仍完全正确**。身体色散场保持真实行走时间，软压力强度乘0.3；它与背景仍是原有线性叠加近似。
- 接触波源步程0.48→0.96m、最短间隔0.4→0.8s、幅度0.012→0.003。身体连续尾迹保留。行走上限仍0.8/1.6m/s。

## 近似与限制

1. 源三角形是局部分片线性光束，有限太阳盘只有三个方向；接收图像素达到约3mm不代表整个波场已具有毫米物理解析度。原水场网格3.125cm、身体场12.5cm不变。
2. 接收三角形若任一端点落在墙/身体等其他面，会整片剔除。遮挡边界存在约一个源网格的保守缺口，没有精确裁切到所有障碍轮廓。内部池底本身无CSG洞面积归一化问题；旧墙面CSG覆盖率逻辑保留。
3. 片内密度插值、有限角度求积、半精度目标和MSAA均是离散近似。极深水或强折叠可能有很尖的峰值；本轮没有作任意波高/水深无闪烁保证。
4. 水平静后大多数区域真实聚焦较弱，光带仍可能偏宽。提高接收保真度无法在缺乏曲率时凭空制造强焦散；不为追求遍地亮网再次增大波浪。
5. 原身体软排水、缺失涡量、内部墙穿透、有限间接光等历史限制保留。
