# v1.7：按施工关系铺贴

零位图；材质全部在运行时由米制位置、表面类型与稳定砖号生成。光传输、连续水波和 v1.6 单像反射保留，保留真实法线反射方向与单峰反射重建，细节与既有物理近似见 [v1.6](PHYSICS-v1.6.md)。

## 放线与裁切

普通墙、柱、池底统一250mm模数，以世界y=0为水平基准，以x/z=0为各正交方向的放线基准。取消砖块随机旋转和随机中心偏移；保留每块的釉面起伏、色差、厚度和小倾斜。名义缝宽5.6mm，槽底位于基底后4mm，圆角/倒角仍由高度场参与主射线求交。相邻共面的拱体原本分别生成砖号，现共用铺贴平面的种子，同一块砖不会在几何分块边界突然变色。

前排起拱线从2.45m调整为**2.50m**，与后排、250mm水平皮数一致。这是本版唯一宏观尺寸调整；拱半径、位置和厚度未改。不能把这5cm改变隐瞒成单纯换材质。

每个半圆分32个相等角区间，左右各16段，拱顶是一条居中的缝。正面/背面的250mm宽砖圈和内弧共用角序列：缝从砖圈端面接入洞口内弧。砖圈外侧与普通墙砖之间有明确的弧形切割缝，墙砖在这里终止，而不是把方格硬拉成圆弧。厚度方向仍沿全场z模数，前排0.8m厚墙分为150/250/250/150mm的对称裁切段。

这是从250mm方砖裁出的弧形楔片，不是另一种随意拉伸的网格。250mm砖圈宽度包含接缝，净砖径向尺寸约244.4mm。前排内/外弧每段弧长约174.8/199.3mm，后排约206.2/230.7mm；外缘弦宽都小于250mm，裁切排程可落在同一规格坯料内。瓷砖是饰面，不把它宣称为承重砌体拱。

## 阳角收口

最终使用 **45°对缝切**。前面和洞口侧面共同计算同一条切平面：距离阳角为d时，砖面高度不高于d−1mm。内弧与拱口端面的外缘也使用相同的45°切面。两面求交得到同一个45°切面，夹角处不再是两块厚砖相互顶穿；水平方向的槽底和皮数继续绕角相接。切面与原有圆角接缝都参与近景主射线求交、法线与局部遮挡。

最初尝试过分段L形瓷质收边，截图留在round-1/2/3，但柱角开销过高；最终没有交付那种收边。当前没有新增独立金属条，也没有用颜色画一条线冒充收口。

## 精度与性能边界

主射线采用局部高度场求交，圆角保持原128步上限和15µm残差条件；能证明在完整砖面内的射线直接解倾斜平面，远离接缝的点也跳过无效的局部遮挡计算；并非把每块砖变成独立封闭网格。局部曲面使用切向近似，次级反射和光子仍使用面积平均材质及宏观几何，不精确解析所有毫米级切边遮挡。极端掠射角、轮廓外侧及未处理的台阶转角不能宣称施工级几何完整。新增近景图展示的是默认材质在固定1280×832下的输出，不用低分辨率截图掩盖细节。

光子、天光、漫反射传播均未减量。相机采样明确重分配：平坦不透明区域2个对角子样本，水面4个，高反差/边界8个（触发阈值由0.7收紧到0.3）。这降低了平坦材质区域的空间求积精度，不能宣称相机样本数量完全不变。反射方向和单像重建不变，没有新增随机采样。近距离仰视/柱角负载很高，旧版同机补测也出现低于30fps；本版使用并调整既有动态分辨率，900ms检查一次，帧间隔中位数>28.5ms时降低尺度，<20ms时渐进恢复，避免旧逻辑在近景降过之后一直停在低分辨率。它不混合历史、不冻结波浪；代价是重机位的实际渲染像素减少，必须结合验收中的实际分辨率看帧率。
