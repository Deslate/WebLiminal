# 向前行走的可见弓浪

基于 main `249dd10`（v1.33 水波 + ESC 暂停），采用 `candidate/ripples-steep` 的紧凑脚步压力，并补回独立标定的身体前向压力。用户已有 BRIEF.md、.flops/ 保留、不纳入提交。没有 push。

## 实现与边界

之前短波候选不只缩短脚步压力，还把身体压力强度及作用范围一起缩小：身体基础强度 0.10→0.025m，动态压力半径 0.25→0.16m。这使前方波场几乎消失；只恢复脚边的法线 RMS 无法解决默认视角可见性。

本轮保留紧凑脚步源，在现有身体压力内加入较宽的前后压力偶极项：

- 方向由实际碰撞后位移速度决定，作用中心仍在身体湿前缘；没有按镜头位置放置激励。
- 压力范围参数 `R=0.23m+水深`，本场景为 0.65m；傅里叶压力为高斯的一阶方向导数，空间积分为零，不凭空增加水量。
- 等效压力水头 `3 × U²/(2g)`。**3 是软压力模型的经验增益，不是人体压力实测结果。** 此模型不是完整 Navier–Stokes 或刚性人体流固耦合。
- 额外宽压力在 0.8–1.2m/s 之间平滑淡出，避免当前线性有限水深求解器在较快运动时过度响应。紧凑身体压力和脚步压力继续存在；1.6m/s 快走没有新增这项宽压力。
- 压力直接进入原有、保存高度及速度状态的有限水深波动方程。没有指定弓浪形状、渲染波纹、独立法线或焦散层。产生的高度及导数仍供水面求交、反射、折射、光子传输共同读取。
- 波场网格、时间演化、默认相机 18.3°/24mm、0.8/1.6m/s 行走速度、背景幅度 0.018/速度 0.28、材质及曝光均未改。ESC 保留。

水面求交的保守搜索范围从 ±0.28m 改为 ±0.34m，另加原有背景波裕量。这是因为换向压力测试发现了 302mm 的瞬时绝对高度，略超原范围。**它只扩大查找真实水面交点的区间，不裁剪或放大波高。** 0.4–1.2m/s、Shift 切换和前后换向共 8 组实测原始值保存在 speed-check.json；初始包围范围断言失败日志也保存在 pre-bracket/，没有删除。修改搜索范围后物理波场未变，bound-validation.json 验证了覆盖范围。

## 前方数据（与上轮相同口径）

从初态重放，关闭环境激励，站立 2 秒后以 0.8m/s 前进。取 t=6 秒、前方 1.2–3m、横向 ±1.5m 的真实 GPU 高度场。法线角由高度有限差分计算，不从反射或瓷砖图像估计。这是世界空间前方区域，不是整张屏幕或身体周围统计。

| 指标 | 原主分支 v1.33 | 上轮 ripples-steep | 本轮 |
|---|---:|---:|---:|
| 前方法线 RMS | 0.765° | 0.084° | **4.650°** |
| 前方高度 RMS | 6.324mm | 0.640mm | 24.675mm |
| 前方最高位移 | 10.606mm | 0.686mm | 96.988mm |

前方法线 RMS 在 t=4/6/8 秒分别为 3.754° / 4.650° / 3.428°，并非只挑选单个最大时刻。停止于 t=8 秒后，t=16 秒前方法线 RMS 为 0.639°，上轮候选为 0.640°；前方高度 RMS 为 0.799mm。新增弓浪消散后没有留下持续激励。

初始站立 0–2 秒，全池高度变化 RMS 为 0.00253mm，与上轮候选一致（原主分支 0.03936mm）；该测试隔离背景，正常背景水波参数未改。停止不会立即把真实波场抹平，仍有自然传播、衰减。

本轮是可见的弓浪／水脊，不把它声称为毫米高细波：前方水脊在上述时刻约 8–11cm；慢走全程每半秒抽样最大绝对高度 184.42mm，包含身后低谷。连续前后换向压力测试每 0.1 秒抽样最高约 302mm。这是当前软压力/线性波场近似的局限，未声称支持任意强烈动作或任意水深。已有内部墙体的身体波反射近似也保留。

## 视觉验收

默认第一人称、真实 W 键：站立 3 秒、向前走 6 秒、停步 7 秒，没有低头、广角或旁观镜头。走动时前方折射的瓷砖线形成连续弯曲带，柱子倒影的下缘被水脊推挤、收窄并向前景延伸；停步后这条扰动继续传播、减弱。查看了完整场景截图及解码连续帧。另给出同一姿态、同一模拟时刻的 before/after 图。

保留的是 3 倍压力水头档；4 倍档的整体起伏过大，未采用。未加速度淡出的最初试验在 1.6m/s 时出现过大的线性响应，未合入。证据原始数据中保留这些被淘汰的档位，不冒充正式实现。
