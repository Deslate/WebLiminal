# v1.13 验收：持续演化的物理波场

本版用GPU非线性波动方程替代全部解析载波和解析脚步波包。实现和近似见[PHYSICS.md](PHYSICS.md)。证据根目录：`/Users/steven/Projects/workroom-v1.13-evidence/`，round1/round2保留迭代，final为交付。截图、录像不进入仓库或构建。

## 七条结论

1. **通过。** 高度/速度状态以360Hz积分，448×864网格。波传播、反射、干涉、衰减与扰动响应来自离散方程，不再通过时间直接求解析波形。
2. **已耦合；最细毛细尺度有折扣。** 大中小尺度在同一状态上演化，恢复力依赖当前局部高度，存在非线性调制；表面张力项参与积分。31.25mm网格不能解析毫米级毛细细波，不能把本实现称作全尺度精确流体。未额外叠解析法线假装毛细波。
3. **有限观测通过，不宣称无限时长证明。** 无平铺边界、时间取模或循环回放。检查34.08秒实际录像、90秒状态演化；同区域20/40/60/90秒高度相关为−0.308至0.418，RMS差7.28–13.40mm，未回到同一状态。重复性仍须以人眼长看为主，这些数字不是审美评分。
4. **通过。** 实际键盘行走注入局部压力，停止源后波继续传播而非被移除。相机、反射、折射、墙面/池底光子读取同一个曲面。有/无三次脚步的严格重放改变水面上方墙面及池底原始辐照度，详见coupling.json。
5. **已测机位≥30fps，保留动态分辨率。** 测得明亮/暗处行走43.84/40.87fps，最低一秒37.43/34.94fps。相机没有随机采样或时域糊图；检查移动与暗处连续帧未见采样斑点或整体跳闪。极低掠射和柱缝仍检出个别单像素亮点，不能宣称所有亚像素闪烁彻底消除。
6. **通过。** 无位图输入/部署资源；模拟存储缓冲是运行时数值状态，不是图片贴图。
7. **通过。** 34.08秒WebM包含约27秒本版静止、真实行走和贴近水面的观察。另给固定机位、固定1280×832内部尺寸、关闭颗粒的6秒/26秒对照。已查看实际图像、录像解码帧及连续帧联系表。

## 物理状态与光学审计

`scripts/simulation-v113.mjs`独立运行生产模拟器，不经过相机作假。零初值、无外力保持零。一次脚步后，半径0.6–2.2m环带高度平方和从0.2秒的2.41e−6增加到1秒的1.82e−3，能量由脚边向外传播；全场能量代理从1秒0.001088衰减到10秒0.000654，源在0.28秒已关闭，10秒仍有回波。30Hz/60Hz显示分步在相同物理时刻全部读回数值差为0。90秒测试无NaN/发散，所检时刻最高绝对波高0.0481m。完整记录simulation.json，固定ROI时间相关见nonloop.json。

三个脚步输入的A/B：池底ROI线性RGB辐照度最大差0.97256、平均绝对差0.03504；只取y>0.6m的墙面，最大差0.02156、平均差0.0004056。差异发生在材质、相机与色调映射前，不是贴图/屏幕特效；脉冲已停止，状态中的传播仍改变光照。

CPU从真实GPU高度场独立重建三次曲面，核验光子路径的高度、法线、Snell、Fresnel和分支通量。最大高度残差1.69e−7m、法线分量残差4.87e−6、Snell残差2.58e−7。模拟状态是核验输入，不再拿被淘汰的解析正弦波当参考。记录coupling.json及proof/。

## 连续性与回归

墙、暗墙、低视角水面、釉面、拱边、柱角各61张连续1/60秒生产帧，低视角/近景含平移和转头。相同物理状态下改变中间相机历史，再返回机位，PNG逐字节一致；这一检查不要求物理波场“无历史”。30Hz和60Hz停步检查均在1秒内达到静止照明档。

六组孤立亮点启发式计数分别0/0/1/0/0/1。低视角共两帧、柱角一帧各检出一个高反差单像素点，已保存坐标和放大裁切，不能隐去；看过正常尺寸帧未见成片采样噪声。相邻帧亮度MAE中位分别5.52/4.26/8.93/4.20/6.00/2.49（0–255），包含真实波动、反射边缘和相机移动，不作为“纯噪声”值。原始序列、分析和限制在synchrony/。

15项单元测试通过；构建/零位图检查、近景凹缝、池底物理量对照、拱模数布局、凹槽射线、301帧沿缝序列、256批照明参考、独立光学证明均通过。regressions.json记录每项退出码。历史v1.12任意相位回跳、脚步过期后等于原始画面的断言不适用于有记忆的物理模拟，已由重放/传播/衰减测试替代。
