# v1.37：背景波和脚步碎波提高空间频率

基线是用户认可的 v1.36 (`8bf4dfc`)。开工时仅 BRIEF.md 和 .flops/ 是用户未提交内容，原样保留；无远端操作。

## 实施

- 背景的两组随机初始位移包，以及持续随机压力源的物理半径乘0.7。中心分布、随机种子、多方向/多尺度生成方式和波方程保留。背景时钟0.28→0.21，以控制缩短波长后的时间变化；默认幅度参数仍0.018。
- 每步回落冲击的Gaussian半径0.105→0.075m。仅对冲击源的波数谱施加径向分辨率截止：18rad/m开始平滑衰减，24rad/m归零；避免激励无法可靠重建的方形Nyquist边缘。它是输入波方程的源离散化，不是水面/图像特效。
- 试验保留原冲量时，慢走全场采样最大波高137→221mm。最终将等效冲量水量18→14.4L/step，让频率提高不主要表现为波峰变大。保留0.48m步程、0.4s最短间隔、六个弹道回落包、真实行走方向、逐步不同且确定的初始动量。没有持续前向力场。
- 未改相机、材质、光子预算、反射折射、行走速度或ESC。全部形变仍来自共享水面高度及其导数，没有新增波纹图案、法线层或焦散层。两个模拟网格均未加密。

## 静止与数值检查

背景在6/12/30s各取相隔1/60秒的一对高度场：逐帧高度差RMS的平均0.18557→0.13763mm（−25.8%）；逐帧斜度向量差RMS平均0.002124→0.002158（+1.6%），单个样本最多+2.6%。因此不是所有时间变化指标都降低，但没有大幅变快；普通视角停止后的水面仍平静。

脚步停止8秒时，前方高度RMS0.557→0.597mm，法线RMS0.454→0.493°，残波自然衰减。没有强制清场或冻结波相。

30/60Hz同单次冲击和停步重测：停步1秒后高度场相对L2差0.1716%，RMS差0.00259mm；记录在refinement.json。0.4–1.2m/s、快慢切换和反向运动压力测试最高213.626mm，低于现有340mm求交包围范围，无非有限数或GPU错误。

ESC行走中暂停3秒：额外提交0、恢复首帧PNG逐像素一致。18项测试、零位图构建通过。

## 边界与折扣

- 脚步波频率确实提高，但**没有达到厘米级水花**。脚步FFT格距12.5cm，轴向Nyquist是4cycles/m（波长25cm）；新径向截止3.82cycles/m（约26.2cm），且截止处趋零。前方平均频率重心约1.95cycles/m，其倒数约51cm，只是谱尺度摘要，不等于每条波纹宽度。继续只缩源半径无法突破这条解析边界；本轮没有扩大模拟预算或引入假高频法线。
- 背景仍用原浅水型有限差分方程和美术时间倍率，不宣称升级为完整短波有限水深模型。
- 沿用v1.36未解析飞溅回落的弹道冲量近似。14.4L是等效强度标定，不是真实测得的踢水量；没有空中飞沫、白沫或完整人体流固/质量动量交换，内部墙体碰撞与反射近似也未修订。
- 频率提升幅度为温和提高，不是数量级跃升。当前正常视角仍清楚可见，≥30fps在本机通过；没有任意设备性能保证。
