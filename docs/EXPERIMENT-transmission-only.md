# 仅恢复真实水面透射（P0）

从 `candidate/no-live-water` / `507febb` 分出 `candidate/transmission-only`，主分支不动。恢复太阳、天光经当前共享水面折射到首个真实接收面的照度，以及匹配的四轮漫反射增量。`water-caustics.wgsl` 的 `waterPacket` 只执行 branch=1：`refract`、`1−F`、水体吸收、接收面涂层透射和面积归一化保持不变。没有把反射能量重新分配给透射，没有按接收面ID画光斑，没有改光源/曝光/材质/波场。

`renderer.js` 恢复实时发射、接收重建、平水参考及漫反射求解；`compose-light.wgsl` 恢复 C+T+ΔD。当前照度和参考都调用同一个仅透射shader，ΔD=Σ(K^k(T当前−T平水))，不能使用原本包含反射的W平水。

`photons.wgsl` 的首个过水接收排除与 `camera.wgsl` 的水下普通直接照明排除保持不变，保证补回的首段透射只计一次。缓存里原有的后续平水漫反射不再重复追加全量，而是只追加动态差值。平水差值、分支权重与缓冲合成分别做GPU读回验证。

省略的是太阳/天光→水面反射→首个接收面的**实时首段**。相机水面反射、缓存既有的平水后续路径，以及漫反射传递中的平均水面Fresnel均未删除。因此不能声称顶面所有间接光或所有时间变化都消失，更不能声称这是完整无偏物理解。这是一项明确省略反射路径的候选。

P1没有顺手调整：不增加波幅/频率，不移动亮区，不改反射滤波。若P0恢复后结构仍不及离线，继续留待独立诊断。

验证脚本：`scripts/energy-transmission-v156.mjs`、`scripts/capture-transmission-v156.mjs`、`scripts/analyze-transmission-v156.py`；完整 `npm run benchmark`；独立固定分辨率及正式动态分辨率帧率。证据与最终数字在 `../workroom-v1.56-evidence/README.md`。
