# G 光传输实验台

本轮基于 `6d4245f`，默认仍为“只留透射 + 覆盖面积漫反射积分”。G 开关面板；关闭按钮和 ESC 只关闭面板。Tab 保持真正暂停/恢复，M/V 的原操作在面板关闭时保留。面板打开时方向键用于选择，阻止 WASD 误移动；可关闭后移动到新机位再比较。

## 控制的是哪一环

| 控制 | 档位；默认加粗 | 实际作用 |
|---|---|---|
| 实时水光 | 全开 / **只留透射** / 全关 | 全开恢复实时太阳/天光 Fresnel 反射分支及相应平水基准；透射保留1−F，不补偿被删反射能量；全关停止实时发射/接收/增量传播，仅组合静态缓存，不给基础光追暗中补光 |
| 额外反射续追 | **0** / 1 | 现有首段真实镜面不受0档关闭。1档在次级固体上追加一次四方向GGX积分，真正求交；该处移除被续追替代的有界环境近似，终端仍有原近似 |
| 漫反射方向 | 32 / 64 / **128** / 256 | 专门编译实际积分方向数；匹配链接缓冲容量和积分归一化，再重建可见性链接 |
| 缓存光子/批 | 49152 / 98304 / **196608** | 改每批真实发射数量；实时正常场景仍128批，按实际数量归一化，不是亮度倍乘 |
| 天光面积采样 | 64 / **256** | 8×8 /16×16开口面积积分，PDF/数量同步归一化 |
| 内部分辨率 | **自适应** / 固定100% /75% /50% | 真正重建相机缓冲并改变射线像素数；固定档不被自适应覆盖，当前尺寸显示在面板底部 |
| 照度格线密度 | 0.5× / **1×** /1.5× | 实际改变共享接收图册的格数；池底约4.17/2.08/1.39cm，保留跨体块共享拓扑；漫反射单元物理面积近似保持 |
| 光子重建范围 | 0.5× / **1×** /1.5× | 改光照域中缓存/实时光子的归一化重建支持，不添加屏幕模糊。格密度变化时同时按比例换算支持半径，存在整格舍入 |

实现位于 `src/lab-settings.js`（白名单/默认/保存）、`src/lab-menu.js`（界面与实测显示）、`src/main.js`（输入/暂停/实验状态）、`src/render/lab-shaders.js`（真实着色器专门化）、`renderer.js` 与共享图册构建。没有新增图像素材或水光图案。

## 时间、保存与读数

切档会暂停提交、等待在途GPU工作、重新建立对应管线/接收缓冲/静态缓存，按同一种子重置波场和实验时间；保留相机位置。这是实验重置，不宣称切换中的水面时间连续。若原先已经Tab暂停，仅重画一张显式参数修改后的画面，再保持暂停。重建期间按Tab只记录最终暂停意图，不提前重新启动渲染。单纯Tab暂停/恢复的时钟逻辑没有改变。

每行显示最近60个 **GPU完成帧** 的整组配置平均fps/ms，每500ms更新；不是RAF计数，不是对该选项的独立耗时归因。未积累稳定帧时显示等待，暂停时显示无新帧。缓存光子和天光预算的主要代价在建立缓存时，不能把几fps的热机/采样波动全解释成稳态因果收益。

设置使用当前浏览器当前站点的 `localStorage`（`poolrooms-light-lab-v1`），刷新后恢复；4173和4175各自保存。非法/旧值回到白名单默认，存储失败不阻止本次应用。一键恢复默认覆盖本地保存。全关仍含静态缓存中的平水间接路径，因此不能把它称作完全不含水光或无偏基础路径追踪。

## 可复现对照

Benchmark 支持真正的实验配置，并把它写入manifest和run.json、加入默认输出目录键；同一目录不能复用另一组参数。默认仍跑原来的九组对照；dense/low控制通过相同菜单API设置256/32方向，避免与编译后的缓冲尺寸冲突。

```sh
EVIDENCE_DIR=../workroom-lab-off VERIFY_URL=http://127.0.0.1:4175 \
LAB_CONFIG='{"waterMode":"off"}' PYTHON=/opt/homebrew/bin/python3 npm run benchmark

EVIDENCE_DIR=../workroom-lab-64 VERIFY_URL=http://127.0.0.1:4175 \
LAB_CONFIG='{"diffuseDirections":64,"resolution":0.75}' \
PYTHON=/opt/homebrew/bin/python3 npm run benchmark
```

自动化接口：`await __POOLROOMS_V1__.setLab({...})` 或 `configure({lab:{...}, ...})`。传入的是一组设置，未提供项用默认值；自动化不写localStorage。`snapshot().lab`/`config`/`dynamics`提供请求和实际参数。固定性能脚本显式选择100%内部尺寸，不依赖旧字符串替换去关闭自适应。

## 验证与限制

本轮证据目录 `../workroom-v1.58-evidence/`：UI开关/刷新记忆/暂停GPU提交检查；全档位真实输出矩阵；同机位默认和旧候选的逐像素比较；完整Benchmark；独立性能。量化结论以该目录README和JSON为准，录像重放速度不当作实时帧率。

相机追加队列扩展为二维间接分派，处理高分辨率的65535工作组限制；4K、8294400像素全部强制追加采样的GPU夹具无验证错误。1.5×接收格的天光计算同样调整工作组大小，解决超过单维工作组上限的问题。两项只改调度，不减少采样。

**高成本实验档不保证30fps。** 额外反射续追尤其昂贵；默认不启用。各档位的单机测量不能当成所有档位组合/所有设备的帧率保证。持久化高成本档后，可用G恢复默认或Tab暂停。新增有限方向续追仍是截断积分，不是完整无限反弹光追。
