# v1.16：放慢背景水波，增强普通行走尾迹

以用户回退后的`ed6fb43`为基线，仅改水波时间推进与普通行走的身体压力强度。不恢复v1.17–v1.30的任何渲染或焦散改动。接手时工作树已有`BRIEF.md`修改和`.flops/`未跟踪目录，均保留且不纳入提交。

## 结果与取舍

背景/脚步细波场的模拟时钟倍率由1降为0.28。同一段背景起伏现在用原来3.57倍的时间完成；波幅、空间网格、驱动分布、材质和光照预算不变。这是求解器时间尺度的有意调整，不宣称符合未缩放重力下的真实秒数；没有冻结波面或混合历史图像。

身体色散尾迹继续按真实行走时间推进，以免减慢身体波后，移动源在模拟坐标里突然变得过快。只对普通行走增大局部身体压力：

`gain = 1 + 0.6 * min(1, speed/0.8) * clamp((1.6-speed)/0.8, 0, 1)`

0.8m/s时增益1.6；站立和1.6m/s快走时为1。这样既增强原先较弱的普通行走，又不放大已较高的快走弓浪。增益作用于原有软压力势；波臂、凹陷、停止后的传播由原有有状态有限水深色散方程产生，没有预画V形或光纹。身体波仍与背景波组合成所有反射、折射和光子共用的水面。

背景变化量使用同一物理波形起点：基线重放到2.8秒，本轮重放到10秒，模拟相位同为2.8秒；再各推进一个显示帧1/30秒。读取x=1–5m、z=−3–1m的真实高度，不从瓷砖画面推算波速。两者起始高度完全相同，证明这里变的是时间而非振幅。

尾迹量测为隔离身体压力实验：无环境初始起伏、无随机环境压力、无脚步包，以免把背景当成尾迹。水深0.42m，身体从x=−2.8m、z=1m站定3秒后出发，走6.4m；慢走0.8m/s取t=11秒、快走1.6m/s取t=7秒，均在相同终点。弓浪取前方0.2–0.8m、横向±0.25m；后凹陷取后方0.25–1.5m、横向±0.25m；后方RMS取1–4m、横向±2m。峰值是相对静水面的高度，不是峰谷差。

加入默认背景的16秒慢／快走压力测试，最高绝对波高分别108.93mm／144.45mm，低于原有215mm水面求交包围范围。普通行走30Hz和60Hz重放的最大高度差0.0646mm。默认录像另包含正常脚步源及真实场景边界。
