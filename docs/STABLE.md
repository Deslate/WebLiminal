# 稳定版记录

## stable-1 — 2026-09-30

**提交**：`2c08187`（主分支）。本地 tag：`stable-1`。

### 这一版包含

- **完整光路**：水面**反射 + 折射（透射）**两条都在；
- **覆盖面积积分**（`e226a19`）——修掉"用约 2.08cm 的单格照度代表约 16.67cm 漫反射单元"的**空间欠采样**；
- **粗糙反射积分**（`b758476`）——修掉"少量积分方向把宽泛反射采成几份景物副本"，即天花板上那种"像照镜子"的假象；
- **暗处天光 64 方向积分**（`2c08187`）——暗顶不再由"每点只连天窗 4 个固定位置"离散化；
- **G 光传输实验台**（`31fb9d1`）——三组八项**真开关**：水光通道（全开 / 只留透射 / 全关）、光追采样（反射续追、漫反射方向、缓存光子、天光采样）、接收与重建（内部分辨率、照度格密度、重建范围）；每行显示**当前整组配置**的实测耗时；默认档 + 刷新记忆。

### 默认渲染未变（合并与修复的验收依据）

- 标准截图：**6,912,000 个 RGB 通道值全部相同**；
- 完整 76 秒路线：**2280 帧、607,027,200 个亮度值全部相同**（重复跑一致）。

### 已知残余（未达标，Benchmark 状态 REVIEW）

- **门洞转身 100ms 差分 p99 = 3/255；暗墙 = 2/255**；
- **明亮的太阳光斑没有被柔化**：太阳方向加到 64、或空间采样加密 16 倍，结构尺度只变化约 **4%**——判断为真实聚焦，**没有用散射去涂开**；
- **性能待测**：镜面采样预算比早期版本增加约 **6–8 倍**，存在明确性能风险；且历次测量时用户机上有游戏占用 GPU（39–46%），不能据此下结论。
