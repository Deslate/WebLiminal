# v1.15 验收：玩家持续占位、行走尾迹和停步传播

## 六条要求

1. **持续占位**：生产玩家绑定直径0.38m的圆柱代理；软位移势持续作用于同一GPU波场。独立静水测试站定3秒时，距中心0.2–0.4m环带平均隆起5.18cm；停步64秒后仍为5.10cm，不会把身体关掉后恢复成空水面。这是软占位近似，不是精确刚体排水体积。
2. **尾迹及停后传播**：实际W键行走录像移动约4.97m。步压与持续身体位移共同驱动已有波场；停步不清空高度/速度。控制序列拍到波从身体向外传播，越过亮区并在池边反射，逐渐减弱。
3. **几米之外可辨**：独立14×27m水域无环境强迫测试，停步1秒时2–4m环带高度RMS为8.32mm；停后32秒为0.926mm，64秒为0.348mm。速度能量代理从停后4秒0.710降至64秒0.0126（约98.2%）；仅统计垂直速度平方，不能叫总机械能。
4. **可观察身体关系**：新增V键固定旁观相机；实际键盘玩家与相机独立。录像中圆柱的浸水段、倒影、阴影、身周抬升和移动尾迹同时可见；另有第一人称低头图。
5. **性能、稳定、资源**：保留九点传播、360Hz积分、连续身体子步插值、原光子预算与确定性相机分支，无新增位图、随机光学采样或图像时间模糊。30/60Hz线性移动驱动的全场读回最大差为0。性能见下表。
6. **交付证据**：`final/observer-walk.webm`为真实浏览器录像；`final/stop-frames/`及JSON包含129张图，停止后前2秒为完整30Hz连续帧，之后每秒一张，直至停后64秒。`stop-overview-sheet-00..05.jpg`与`stop-continuous-sheet-00..05.jpg`便于逐张检查。

## 证据解释与剩余限制

真实行走录像为37.00秒（实际模拟观察30.56秒），保留默认环境波和胶片颗粒。已检查全程每秒抽帧及五个原生25Hz窗口的125张连续帧，未见新增采样噪点或跳闪。录制、启动和PNG读回有开销，录像容器时长不等于模拟时间；没有后期减速，录像不用于测帧率。停步衰减控制序列关闭环境强迫、初始粗糙度设为0.00001，以隔离玩家产生的波；这不是把生产水面停掉。生产场景有持续环境扰动，因此不会最终变成完全静止的镜面。回放均连续积分，没有从时间直接合成波纹；指定时间步PNG不作为实时性能证据。

停后完整61帧中孤立亮像素检测最大值0，相邻亮度MAE中位数1.66/255、最大4.08/255；差分包含真实水纹运动。人工检查所有停步概览和连续帧，观察到向外连续传播而非采样斑点。另检查两组人物与第一人称相机同时移动的60Hz序列（明亮/暗处各61帧），孤立亮点均为0，相邻亮度MAE中位数分别5.45/0.678（255量程）；人工逐张检查未见噪点闪烁。该统计不能证明所有视角的亚像素闪烁绝对为零。

折扣：身体是简单圆柱、着色简化，暗处代理身体偏亮，不是完成的人体材质；软位移势不等于精确不可穿透刚体边界，未做人体关节、湍流或飞溅。水中冲刺已限为1.6m/s，失败的2.4m/s应力记录未删除。固定旁观相机不做墙体避让；主视角的玩家碰撞仍在。未穷举任意极端水深/波高、长时间往返、所有设备与视角。

最后补查了环境波高精确为0的情况：身体驱动仍演化，1秒峰值10.15cm，GPU无错误。光学读取不再因为环境波高为0而绕过身体生成的波场；无人物平水参考仍保持平面。
