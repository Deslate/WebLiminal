# v1.12 验收：自然波面与行走涟漪

证据：`/Users/steven/Projects/workroom-v1.12-evidence/`。before为v1.11，round1/round2/round3保留迭代，final为最终交付。所有图像仅作仓库外证据，无位图进入程序。

## 六条结论

1. **显著改善，未宣称任意区域/无限时间绝无规律。** 两个连续随机场调制多尺度波的局部相位、方向及振幅；不设循环时间、不逐帧重新抽随机数。看过三轮实图后加强局部调制。固定世界辐照度ROI的非零位移峰值相关由0.885降至0.366（中间轮0.561）；方法与限制见下。
2. **同一光传输随波面自然化。** 细光线密度和聚焦强度随局部曲率变化，没有另加池底图案或增亮系数。仍受2.083cm接收格、3×3重建限制，最细丝线较软，尚非完整照片级焦散。
3. **通过。** 真实键盘行走触发脚步源；传播、衰减、叠加进入真实波面高度和法线，反射、折射、墙面和池底光子传输共同响应。录像记录14个脚步事件，停下后继续传播、随后消失。无角色实体流体排水或岸壁反射模拟。
4. **已测状态通过，动态分辨率有折扣。** 真实行走、明亮与暗处独立GPU完成帧测试超过30fps。参数预算未削减，新增成本为波面求值。连续帧中未见新的采样噪点/明显跳闪；柱角仍有一个旧的孤立亮点，极端掠射走样未保证消除。
5. **通过。** 程序波场、世界坐标、解析导数，零位图源/部署资源检查通过。
6. **通过。** 近照、真实键盘行走录像、同机位同时间有/无脚步对照、原始连续帧均交付，并已查看录像解码帧、近照和连续帧联系表。

## 物理耦合与连续性

同时间有/无脚步的真实GPU辐照度缓冲差：池底ROI RGB最大19.203、平均绝对差1.139；侧墙整体红色通道最大0.3134、平均绝对差0.00447。它们在材质、相机、曝光处理之前已不同。原始数组及独立光学核验在wake-coupling.json，数据单位为渲染器线性辐照度，不是显示像素差。

固定相同脚步源集合，同相位重复渲染PNG逐字节一致；改变中间历史再返回同一时刻仍一致。全部脚步过期后，画面与无脚步对照逐字节相同，证明没有静态烘焙残留或时域拖影。原始断言在wake-continuity.json。

池底/墙面各61帧孤立亮点计数均0。相邻亮度MAE中位4.127/2.308（0–255单位），包含真实波动、相机运动和边缘采样，不解释为纯噪声。另有墙、暗墙、低视角水面、釉面、拱边、柱角各61帧；前五组亮点计数0，柱角最大1。检查阈值和联系表在wake-frames/analysis.json、synchrony/analysis.json；像素启发式不能保证任意场景绝无闪烁。停止细化在30/60Hz时间步下1秒内达标。

## 重复性辅助度量

取x=[2,4)、z=[-1.5,0.5)的2×2m世界池底直接辐照度，时间14.7秒，不含砖材质、相机折射或色调映射。在±30个格点的二维整数位移中，排除半径<6格的近邻，求重叠区域的Pearson相关。最大值v1.11为0.88495，v1.12为0.36605。只是单区域单相位的辅助证据，不能等同于真实感评分或全局无重复证明。脚本analyze-natural-v112.py。

15项单元测试通过，包括碰撞/传送不产波、连续行走产波、干地不产波，以及随机调制/波包干涉法线与数值差分一致。构建、零位图检查、旧近景/沿缝回归、布局160点、凹槽GPU射线、256批参考、独立Fresnel/Snell/波面核验通过；物理光路核验最大Snell残差约3.42e-7、法线残差约1.57e-6。

实现与保留近似详见PHYSICS.md。不声称完整流体模拟；没有真正的破浪、飞沫、实体排水或边界反射。
