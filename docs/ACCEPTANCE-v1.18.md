## 逐项结果

1. **世界坐标材质已实现**：污渍、暗斑、磨损分布、色调、水垢、釉面微起伏按 h.p 三维世界坐标生成，不以砖面局部 UV 或砖 ID 重置。砖缝及实际施工高低仍保留各自几何逻辑。
2. **明暗检查已做**：两个暗区的近照和单砖近照、一个亮区同尺度对照，另看站立广角和更暗的后室。水下简化材质原本没有污渍细节，本轮补入同一套世界材质。
3. **所检视角未见逐砖复制，严格原症状未完整复现**：旧版存在柔软暗团、砖面单调；恒定相机材质 A/B 中暗团仍在，不能全归咎于局部 UV 污渍。没有用户截图的精确机位，不把有限视角的阴性结果说成全场景无条件证明。
4. **保留脏污**：同机位放大对照中新版存在不同大小、位置的暗污斑及浅色矿物沉积；相邻两砖不是同一模板。没有统一洗白、统一加深所有砖边或改变正常曝光。
5. **性能、稳定、零位图**：下面为独立性能。明暗两组 30Hz、每组 121 帧（4 秒物理时间），逐张联系表检查，共 242 帧；暗组还按相同 display RGB ×5 检查。没有观察到新引入的随机采样斑点或闪烁。原有高倍砖缝边缘锯齿仍可见，不能声称像素级无瑕疵。
6. **证据已保存**：见下面路径。×5 图片全部显式标注，保留正常亮度原始文件。连续序列为确定性步进渲染，不用于性能计算。

## 回归与残留

`npm test` 的 16 项、零位图构建通过。`regression/regressions.json` 中近材质、池底响应、排砖、洞口接缝、沿缝连续视角、波光耦合、非循环、运动/停步、独立参考、光学 proof 十项通过。运动回归在 30/60Hz 下均于一秒达到静止档，六个机位同一物理状态不依赖相机历史。第一次 near 误用了未重建的 dist；重新 build 后通过。一次 motion 被 Vite 热刷新打断，停止源码编辑后重跑通过，这两次不是悄悄删去的性能失败。

另扫描六组各 61 帧的历史回归机位：墙、暗处、低水面、釉面、拱内的孤立亮点判据最大为 0；柱角为 1。`corner-004.png` 的 (110,327) 处出现单像素高对比亮边，放大图 `review/corner-isolated.png` 已亲自检查，位于几何缝角。因此严格的像素级“零闪点”不作通过声明。池底本次两组 242 帧未观察到此问题。

补充回归 `remaining/checks.json` 五项全部通过：完整应用、背景模拟、身体模拟、身体对墙/池底光照的耦合、真实键盘慢/快走旁观录制。录制产生文件用于回归留档；本轮材质稳定性的目视结论使用上面已逐帧看的明暗池底序列，不将未逐帧审看的旁观录制冒充已审看证据。


补充材质隔离图 `material-only/comparison.png` 已逐张看过：仅诊断时旁路场景光照，旧版透水砖面基本均匀，新版相邻砖可见不同位置和形态的污渍。图上明确写有 ALBEDO DIAGNOSTIC，不把这组图当成正常暗处画面。初次诊断因优化去除未使用绑定得到黑图，已修正保留绑定并重拍，最终文件为上述有效图。
