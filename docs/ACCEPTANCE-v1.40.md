# v1.40：墙面镜面反射的距离截断

基线 c5d70b7。本轮生产代码只改 `src/render/camera.wgsl`：取消釉面反射的相机距离衰减和关闭条件。水波、材质、粗糙度、照明网格、反射滤波、光子预算都未改。保留用户 BRIEF.md 和 .flops/；不 push。

## 复现：从哪里开始消失

观察右侧外墙 x=7，沿 z=1.3 从墙前2m退到10m，眼高1.62m，yaw=−π/2、pitch=0.32。采光口在釉面上的蓝色倒影，旧版随远离迅速淡去；5m、7m、10m处已没有方向性倒影。

准确界限来自旧代码：`near = 1 - smoothstep(3, 5, h.t)`；仅在 `near > .001` 时发出反射射线，最终反射再乘 `near`。因此是**3–5m 的人为平滑淡出，末端彻底关闭**，不是恰好5m处从完整反射突变成零。这里的米数是相机到命中点的射线长度，不是垂直墙距。当前俯仰角下，屏幕中央对应墙距约2.85m开始淡出、约4.71m停止追踪（.001分支阈值；5m射线距离对应墙距约4.75m）。斜看墙面时，同一墙距也会更早跨过阈值。

## 根因与排除项

1. **直接根因：主相机釉面反射的3–5m门控。** 反射接收点本来用 `trace(..., INF)` 求交，没有5m射线长度上限；是发射之前按主命中距离把整个反射路径关了。
2. **reflection-filter 不是消失根因。** 原版仅关闭滤波，在5m处仍没有倒影；修复后保留原滤波则有倒影。滤波归一化权重、标准差上限1.1像素（墙面），不会按5m把能量清零。固定接收距离时公式中的主距离增加反而减小投影核。修复版开/关滤波的最终8位图平均绝对差约0.13–0.23级，p99为2–4级，主要影响细边缘，不是倒影开关。
3. **粗糙镜面照度近似不是该距离界限。** `photons.rgb * coat * .08` 没有3–5m范围。旧版删掉它仍无法恢复5m倒影，反射缓冲依然为零。这一小项是原有近似，未拿它顶替远处反射。
4. **材质确有3–5m LOD。** 法线/颜色等细节渐变为 filteredMaterial，远处釉面仍有非零coat和有限粗糙度；这会改变倒影细节，但不会把整条镜面路径清零。保留完全相同材质，移除门控即可恢复，故本轮没有扩大到重写材质。

墙面倒影本来就有真实反射射线，只是旧版限制在近处；不能把整个项目描述为完全无近似的路径追踪。

## 修复与原始量测

删除 `near` 及其乘法，釉面继续按真实法线反射、Fresnel权重、几何求交、遮挡和二次水面反射/折射计算，不受相机距离开关限制。没有增加镜面强度，没有贴图或屏幕覆盖层，没有改变采样数与滤波宽度。

测试页面只读拷贝真实 reflectionBuffer 的中央像素，以下是**滤波和色调映射前的线性反射亮度**，不是整幅图亮度。两版固定t=12，同相机、body:false、关闭胶片颗粒；只用于诊断，不是正式场景冻结。

## 性能与环境限制

Apple M3 Max / Chrome 153 / WebGPU Metal，内部固定1280×832，GPU完成帧计时，关闭自动分辨率调整。暂停其他打开的本项目页面；新旧串行，不同时录像或截图。机器同时有视频/远程桌面等用户活动，不能声称GPU环境完全隔离，更不能沿用v1.39的60fps结果。没有为了测试结束用户的其他应用。

新增远处真实反射有成本。近景小幅上升属于运行波动，不是优化收益。首轮近墙测试平均30.13fps、最低1秒29.87fps，严格最低1秒断言未通过，保留在 performance-wall；随后连续新旧复测见 performance-wall-before / performance-wall-confirm，均通过。更早一次环境未隔离的失败测试19.2–19.8fps也保留在 performance-unoptimized（名称仅为中间记录，期间没有降低画质或实施所谓优化）；重新暂停项目页面后复测为表中值。

**结论：本轮最终独立渲染测试平均及最低1秒达到30fps，但没有证明任意外部GPU负载下始终≥30fps；初测确有低于底线的时段。** 不隐去失败轮次，不把录屏帧率当成性能测试结果。
