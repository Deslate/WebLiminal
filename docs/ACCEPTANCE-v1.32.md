# v1.32：第一人称近身波的可见性

本轮基于 `3db29e7`，保留 v1.31 池底重建修复、背景时间倍率 0.28 和身体压力增益 0.6。没有恢复被回退的短波实验。开始时只有用户的 BRIEF.md 和 .flops 未提交，本轮不包含它们。

## 观察与改动

原默认机位几乎平视（pitch 0.028、28mm）：1280×832 画面底边与水面的交点约在身体前方 3.1m，而强弓浪位于近身不到 1m。仅增加波高不能解决视野外的问题。俯看后又发现压力脊很窄，且最靠近身体的部分被已有圆柱身体遮住。

正式改动两处：默认 pitch 改为 -0.7（向下约 40°），焦距 28→14mm；身体占位高斯压力半径 0.24→0.36m，动态前后偶极压力半径 0.17→0.25m。没有增加压力振幅参数，没有直接放大着色法线。共享有限水深色散状态计算出的高度及梯度仍供水面相交、反射、折射使用。压力足迹是软身体近似，并非精确人体流固耦合。

录像的可见对象是前方弓形水脊：走动时近处瓷砖线弯成弧形，水面倒影随之拉伸；停下后扰动散开。第一人称向前看不能展示身体后面的完整 V 形尾迹。相机调整让近水占据更多画面，也减少上方建筑占比；鼠标仍能自由抬头，抬头后近身波仍可能离开视野。没有声称任意朝向都能看见自身波纹。

## 波高与法线

关闭环境波隔离身体压力，0.8/1.6m/s 从同一起点移动 6.4m；同一终点测量。法线角由 GPU 高度场的 31.25mm 中心差分计算，是物理坡度指标，不是屏幕像素对比度。数据：`visibility-metrics.json`；复现：`wake-visible-v132.mjs`、`visible-metrics-v132.py`。

| 指标 | 改前 | 改后 |
|---|---:|---:|
| 慢走前方波峰 | 87.54mm | 67.42mm |
| 快走前方波峰 | 129.90mm | 138.48mm |
| 慢走固定前方区域法线 RMS | 3.227° | 3.484° |
| 慢走该区域最大法线角 | 16.951° | 9.193° |
| 相同新相机下，可见法线角 >2° 的面积 | 0.379m² | 0.857m² |

固定前方区域为身体前 0.4–1.5m、横向 ±0.75m。可见面积限定前 0–4m、横向 ±2m，包含视锥及身体顶盖遮挡；它是几何可见性估计。原默认相机中这一阈值面积为零。相机与压力宽度的贡献不能混为振幅提高：慢走峰值反而降低，近身水脊更宽，最大坡度更缓。快走峰值增加约 6.6%，不是完全不变。

环境波振幅和时间倍率不变。隔离慢走停步 4 秒后，后方固定区域高度 RMS 为 0.965→1.091mm，法线 RMS 为 0.461→0.313°；静止占位足迹变宽，但没有新增持续激励。

## 性能与校验

单实例 Chrome headless / WebGPU，1280×832，独立于录像执行；没有改光子预算或降低内部尺寸。使用既有六场景性能脚本，明暗两处、静止/慢走/快走，测试俯角 -1.12、正式焦距 14mm。各场景平均 **37.12–38.25fps**，最低一秒窗口 **32.23fps**，p95 最差 33.2ms。最慢单帧 38.9ms，因此不宣称每个单帧都短于 33.3ms。首帧 502ms。完整数据 `performance/performance.json`；不沿用上轮 60fps 背书，也未以同条件 A/B 确定这次性能变化的全部原因。

`npm test` 16/16、`npm run build` 通过。旧版身体压力压力测试通过，峰值 154.70mm，30/60Hz 高度最大差 0.0611mm（该测试使用其既有未增强标定，不等于上表正式慢走参数）。六机位各 61 个连续相位、相机历史独立性与光学检查通过；见 `stress/`、`motion/` 及日志。没有添加贴图、假波纹、独立法线效果或焦散层。
