# v1.36：逐步踢出的前方碎波

基线 main `1738234`。开工时仅用户的 BRIEF.md 和 .flops/ 有未提交内容，均保留。未改相机、材质、光子预算、环境波速度、行走速度或 ESC；未 push。

## 改法与物理口径

原版持续移动的 0.65m 半径身体压力制造低频大弓浪。删除该额外宽压力，保留小范围身体占位/动态压力。脚步仍由碰撞后真实步程 0.48m 触发、间隔至少 0.4s、左右交替；正常 0.8m/s 约每 0.6s 一步。局部脚掌压力减半，让主可见扰动由一次次冲击产生。

新增 `kick-impacts.js`，采用**未解析飞溅的弹道冲量近似**：每一步从实际脚位置发出六个等效水包，方向围绕真实行走方向分散，不读取相机。水平速度 2.8–4.6m/s、向上速度 1.8–2.7m/s，以 g=9.81 求出 0.367–0.550s 的回落时间和回落位置。每步不同、确定性种子保证复现，随机数只生成初始动量，不逐帧生成噪声。速度和水量是标定参数，不是人体流固求解结果；等效水量为每包3L、每步18L。

回落把局部 Gaussian 压力冲量（标准差0.105m）施加到现有有限水深谱波方程的垂直速度状态。每个波数的速度增量为 `-k*tanh(kD)*(V*|vy|/cellArea)*exp(-sigma²*k²/2)*phase`。按准确回落时间求本帧余下时间的振子响应，而非每帧重复注入。DC 不受激，波场没有凭空增加水位。随后完全由原有色散和阻尼传播，水面几何、反射/折射、光子均读取同一个高度及其导数。没有预设圆环波函数、法线贴层、白色水花贴片或独立焦散。

FFT 网格、36 passes、状态缓冲不变，仅每帧实际发生冲击时增加最多12个事件的谱源求值；uniform 从9KiB增为18KiB。不以提高整个波场分辨率换效果。

## 同区域测量

关闭环境强迫以隔离脚步/身体波，水深0.42m、正常0.8m/s，先站2秒、走6秒、再停8秒。从重置完整推进，30Hz；前方ROI固定为距身体 **1.2–3m、横向±1.5m**。法线来自共享高度场梯度。频率为ROI去均值、二维Hann窗后高度功率谱的径向频率重心；不是从瓷砖照片测频率，也不把全池指标混进前方。

全场慢走采样最大绝对高度184.419→137.408mm；快走141.708→136.409mm。另以0.1s采样压力测试0.4–1.2m/s、Shift切换和反向运动，最高173.115mm，未碰到现有340mm水面求交包围界限，无NaN/GPU错误。

未走动时 t=2s 的新旧场差 RMS 为0.0000000545mm（浮点舍入量级）。停步后不继续生出脚步，但已发出的冲量/波继续演化；停8秒前方RMS法线0.639→0.454°、高度0.799→0.557mm。没有用停步清空波场冒充平静。

## 没做到和近似

- **没有可见的空中飞沫、白沫、翻卷破浪。** 实现的是未解析飞溅回落的动量源和它激起的水面波纹；飞行中的水包不渲染。没有求脚部流固边界、喷出水量、水平涡量或完整质量/动量交换。18L是等效冲量强度标定，不能作为真实趟水水量报告。
- 高频是相对原有几米尺度而言：本次频率重心约1.6cycles/m，对应约0.6m，不是厘米级飞沫/毛细纹。0.125m谱网格不能解析厘米波。不声称已经做到了完整“稀里哗啦”的真实水花。
- 弹道源不做内部墙体碰撞，谱场内部墙体无精确反射的旧近似仍在；当前证据覆盖默认第一人称开放水域，贴墙踢水未经完整验证。
- 看过录像抽取的连续帧及原尺寸关键帧，前方碎波明显程度较旧版提升；是否达到用户心中水花强度仍是视觉判断，不能以指标代替认可。未给出任意设备≥30fps保证。
