## 固定路线与输出

路线定义在 `scripts/roam-v149-path.mjs`，共 76 秒、30 Hz、640×416、2,280 帧。角色实际触发脚步/身体水动力，并逐帧检查位置合法性。走动段使用能看见胶囊的跟随相机，检查段停在第一人称附近。

| 秒 | 内容 |
|---|---|
| 0–4 | 水面、胶囊、静止 |
| 4–17 | 明处向第一道门洞走 |
| 17–25 | 转向、门洞内壁 |
| 25–31 | 走过门洞后回头仰视来路、天窗与墙 |
| 31–47 | 暗处行走、更深门洞内壁 |
| 47–66 | 返回明处，保留角色和脚步 |
| 66–72 | 用户截图对应的仰视暗墙/天花板构图 |
| 72–76 | 近距离瓷砖与缝 |

由于没有用户截图的相机坐标，仰视构图是人工匹配，不宣称像素级同机位。视频是确定时间步的完整物理重放，**不是实时帧率证据**。叙事性 34.6–43 秒整体熄灯事件在测试入口绕过，避免把设计事件误报为局部噪声；生产代码未改。胶片颗粒保留。

每轮：`roam.mp4` 彩色视频、每秒 PNG、编码前 `source-luma.npy`、逐帧姿态/时间 `manifest.json`、源码快照、`analysis.json`、各停留段最异常片段和三帧对照。最异常短片是灰度诊断版；观感请看完整彩色视频。全程视频解码核查，另外量化编码误差。

## 判读与阈值

固定相机段舍弃切换后首秒。按真正的主射线命中生成表面 ID 和太阳遮挡掩码；门洞指标只统计拱洞**内表面**，不把旁边的天花板归入门洞。直接太阳不可见并不意味着没有反射/间接光。

亮度范围 2/255–0.40；每个 8×8 测量块至少 90% 属于目标表面。100 ms 差分必须同时超过 2/255 和该块平均亮度的 5%；至少 4 个相连块、覆盖目标暗区至少 0.5%，并连续两帧满足才触发 REVIEW。保留 p99、最大值、连通域面积/位置、频谱重心、3 Hz 以上功率、孤立大跳变数。8×8 平均只用于统计，**不改变交付图像或渲染**。

移动段采用前后向一致的光流重投影，报告残差 p99；遮挡、反射视差和流估计失误仍会产生残差，因此移动残差不能独立判失败。固定段是主要定量证据。

这些是可调整的工程筛查阈值，不是经过人眼实验验证的通用真实感阈值。一个真实焦散也可能触发，必须结合下面的因果对照；未触发也不是无条件通过。

## 真实变化与数值误差的分离

相同路径、初态、时间逐一运行：

- repeat：检查复现性；允许最大亮度差为 0。
- no-glaze / rotated：去釉面链路、旋转釉面积分方向 45°。
- no-diffuse：只去当前漫反射传输修正。
- static-light：再去当前水光接收项，保留背景照明、运动水面、胶片颗粒。
- rotated-transfer / dense-transfer：漫反射积分方向旋转 45°、32→64 方向参考。后者只用于诊断，缓冲和代价更高，不进入生产。

100 ms 差分 RMS 降到基线 25% 以下（基线须大于 0.5/255）标记该光照链路主导；旋转后的差分误差大于基线 RMS 的 50% 且大于 0.5/255，标记积分方向敏感。关闭链路只能说明变化从哪里来，不能证明原结果正确。旋转与加密控制用于揭示欠采样；64 方向仍不是绝对真值。

## 本轮实测

八组均完成 2,280 帧，无页面/渲染错误。全部编码前亮度值的重复误差为 0。主视频与连续帧检查：天花板、暗墙的淡云块跨砖缝变化；更深门洞自身极暗，邻近天花板的变化不能算作其内壁证据。

| 当前基线区域 | 100ms 块差分 p99（0–255） | 最大相连块 | 最大异常暗区比例 | 时间频谱重心 | 标记帧 |
|---|---:|---:|---:|---:|---:|
| 第一道门洞内壁 | 2.984 | 340 | 21.30% | 1.180 Hz | 25 |
| 深门洞内壁 | 0.188 | 0 | 0 | 0.781 Hz | 0 |
| 暗墙 / 天花板 | 3.297 | 28 | 5.40% | 0.986 Hz | 135 |

深门洞 RMS 为 0.0476/255；这里**没有复现超过阈值的爆闪**。第一道门洞的统计已排除太阳直射区域，但仍可能收到水面反射，不能从“暗处”直接推出“没有真实照明”。

以当前 100ms 差分 RMS 为 100%：

| 对照 | 第一道门洞 | 暗墙 / 天花板 | 近墙 |
|---|---:|---:|---:|
| 关闭釉面 | 100.9% | 102.1% | 101.7% |
| 关闭当前漫反射修正 | 101.7% | 39.0% | 10.3% |
| 再去当前水光项 | 9.0% | 5.7% | 9.3% |
| 漫反射 32→64 方向 | 125.8% | 72.9% | 57.2% |

暗墙 p99 随 32→64 方向由 3.297/255 降到 2.374/255（−28.0%），最大相连块 28→14。第一道门洞没有同样改善，不能把一条原因套用到所有位置。旋转漫反射积分后，暗墙与近墙触发 `DIFFUSE_QUADRATURE_SENSITIVE`；釉面积分旋转没有触发。暗墙有明确的漫反射积分采样敏感性；当前实现每个探针只有 32 个方向，每条传输链固定读取命中的单个照度格，再把随波变化的水光传给暗面，因此角域欠采样是有依据的嫌疑。它不是逐帧重新抽随机数产生的噪声。

这些控制识别了链路和采样敏感性，**还没有证明所有剩余变化都是真实、也没有完成云状闪动修复**。64 方向只是参考，不合入场景；没有通过模糊或压对比把指标做低。自动结果为 REVIEW。

## 独立实时性能

`node scripts/performance-roam-v149.mjs` 使用生产调度器、GPU 完成帧和相同 76 秒相机路线，没有录像、编码器或并行参考渲染。已暂停另一个项目页面；用户其它应用仍在运行，不能保证整机 GPU 完全空闲。1280×832 窗口，保留生产动态分辨率，不把低分辨率冒充全分辨率。

| 路段 | fps | 内部分辨率（起→末） | 最低完整一秒 fps |
|---|---:|---|---:|
| 水面 | 49.85 | 1280×832 | 49.55 |
| 明处行走 | 38.50 | 1280×832→1192×776 | 33.43 |
| 转入门洞 | **28.72** | 1008×656→920×600 | 有效窗口不足一秒 |
| 第一道门洞 | 36.78 | 832×544 | 36.50 |
| 回头仰视 | 40.28 | 832×544 | 39.72 |
| 暗处行走 | 49.26 | 832×544→992×648 | 39.18 |
| 深门洞 | 37.13 | 992×648 | 37.17 |
| 返回 | 46.40 | 992×648→1040×672 | 32.13 |
| 暗墙天花板 | 34.86 | 1040×672→768×496 | **29.68** |
| 近墙 | 48.25 | 768×496 | 47.79 |

所以**没有达到全路线 ≥30fps**。Tab 的同尺寸暂停/恢复回归单独通过，不等于任意机位性能都通过。Benchmark 没有修改生产渲染质量，也没有靠调低本轮画质获取性能通过。测试与构建：23 项测试通过，构建通过。

## 边界

测评建立并执行不等于修好了所有光影。深门洞若没有复现超过阈值的变化，必须报告没有复现，不能借邻近天花板的异常冒充。v1.47 的细波时间演化本轮尚未修改，避免在定位期间更换波场而使对照失效。
