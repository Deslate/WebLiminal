# v1.5：当前时刻的水光传输

材料、接缝高度场、釉面反射的实现与限制保持 [v1.4 归档](PHYSICS-v1.4.md)。没有位图资源。本版删除了 0.4 秒关键帧、未来缓存和光照时间插值；没有相机历史累积或时域降噪。

## 每一帧如何产生墙面光斑

`water-caustics.wgsl` 在世界坐标水面上做固定空间求积。每一帧都用相机水面相同的 `U.state.x` 求十层连续波的高度、梯度；检查光源到水面的遮挡；分别沿 Fresnel 反射和 Snell 折射方向追踪实体接收面，并计算空气/水中吸收、接收面涂层透过率和接收面积。两个介质分支都计算，不随机挑选分支。没有投影图案。

太阳水面网格 384×384，天光水面网格 128×256、每点四个天窗位置：合计 **278528 个入射光包/帧**，每包最多两个接收方向。太阳路径用中央太阳方向（有限太阳圆盘未在这条实时支路积分）；水面天光为四点面积求积。实体表面的直接天光仍是原来的 **64 点**积分，这两者不要混淆。

光通量用确定性的整数累加，双线性分配到世界接收格。格宽约 4.17cm；当前焦散用半径三个格的三角空间核（约 12.5cm 支持半径），比旧静止四格、移动六格更窄。有限核仍会损失很细的**空间**焦散，不会混入其他时刻或平滑掉时间变化。几何遮挡和光包离散积分仍是有限精度近似。

## 间接光与预算

保留 **49152×128=6291456** 条、最多 12 次交互的全局光子路径，初始化计算一次平均水平水面下的漫反射背景。剔除第一次水反射/折射后直接落到实体的焦散项，避免与实时水光双计数。这不是把 128 批降低成更少批，而是避免每 0.4 秒重复计算背景。

动态漫反射用预计算几何传输关系：73225 个约 16.7cm 的低频探针，每点 32 个半球方向；遇水分成两个介质分支，共 64 个链接。每帧从“当前水光减去平水光”的变化量出发，执行四次漫反射传播，叠加到高密度背景。四次传播全部用当前时间，不读取上一帧。CSG 空洞探针无效，插值按有效面积重新归一。

**明确的折扣**：背景是平均水面解，动态间接光是围绕平均水面的有限方向线性响应；二次漫反射经过水面时的可见性和折射方向没有逐帧重新追踪波浪。它不等价于每帧完整的无偏多次反射路径追踪。32 方向和 16.7cm 动态探针不能解析所有间接光细节。高分辨率背景、直接水焦散及相机水界面不受这个低频探针分辨率限制。

传输链接约 150MB；每帧四遍读取是新增常驻带宽成本。链接按方向连续排列，相邻 GPU 线程读取相邻记录，避免按探针排列造成的大步长访存；不减少任何链接或计算次数。移除旧的三时刻光照缓存。没有降低相机样本、近景材质质量或默认分辨率。原有负载自适应分辨率仍在，录像开销也会触发它，验收必须报告实际分辨率。

停止后 0.8 秒质量权重从粗背景核过渡到细核；水焦散始终逐帧更新，不等待停止。移动回落仍为 0.35 秒。胶片颗粒 .004 保留。

贴墙压力测试暴露了相机里重复重建探针照明、移动档重复追四个天窗方向的开销。本版新增逐世界格光照合成，再由相机双线性读取；动态低频探针多一次重建到细格的插值。移动档也复用既有 64 点实体天光积分，不再重复追四点。这个积分采用宏观法线、天窗中心方向的局部砖缝遮挡，与原静止档相同；不是对每个微法线重新做 64 次追踪。细微法线仍用于太阳高光、釉面反射和 Fresnel。

## 仍未解决的釉面问题

高反差釉面倒影的锯齿、分层和发虚来自相机一层四方向的有限反射锥积分，与旧 0.4 秒墙面光缓存不是同一根因。本版没有重写这条反射路径，不能声称它已修好。详见 v1.4 材质归档。

## 如何验证

`verify-v15.mjs` 分别采集明墙、暗墙 60Hz 相位序列，检查每帧水/焦散/漫反射时间相等；跳相位后回到同一时刻必须逐字节一致。它还以 CPU 独立重算 GPU 输出的水面高度、法线、反射、Snell、Fresnel 和光通量权重。`proof-v1.mjs` 保留改水位/改开口的因果对照。录像和独立 GPU 完成帧率见 [验收记录](ACCEPTANCE.md)。
