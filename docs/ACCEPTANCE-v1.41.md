# v1.41：远处瓷砖法线与粗糙反射

基线12659b5。原有用户 BRIEF.md、.flops/ 保留。只改材质法线重建及不透明表面的粗糙镜面采样；水波、玩家扰动、光子照明网格、几何和碰撞不变。不 push。

## 复现与根因

同v1.40右墙路线，眼高1.62m、z=1.3、yaw=−π/2、pitch=.32，垂直墙距2/3/4/5/7/10m。旧版约3–5m逐渐失去凹凸造成的反射形变，5m后采光口成为清晰整齐的倒影。上一轮取消反射距离门控，确实暴露了原先被门控隐藏的缺陷。

有两个独立问题：

1. `surfaceMaterial` 在3–5m把法线混合成几何法线，5m直接返回 `filteredMaterial`。没有保存被消除的斜率方差。粗糙度虽由详细材质渐变为 `.17+.10*tileId`，但不是根据丢失的法线能量计算。
2. 相机环境反射仅追踪中心镜面方向。roughness只进入最多1.1像素的后续滤波；即使粗糙度已有约.2，环境反射仍不是该粗糙度的角度积分。仅提高roughness数值不能真正消除镜子感。

这里还有一个需要纠正的尺度判断：1280×832、5m近法向观察时，一个像素约覆盖6mm，25cm瓷砖仍占几十像素，并非一像素已经覆盖很多块砖。毫米级釉面细节应渐进平均，仍可分辨的倾斜/凹凸不应仅因距离到5m全部清零。

## 改动

**按真实像素足迹保留法线矩。** 从相机距离、焦距、入射角和瓷砖局部切线估算两轴覆盖范围，在足迹内作2×2 Gauss采样。每个样本都求原来的程序化瓷砖斜率：真实倒角、砖面倾斜、微观釉面与缓慢起伏。计算斜率均值 μ 和方差 `E[s²]−μ²`；均值生成平均法线，不再按3–5m强制混成平面。

**丢失的斜率方差进入NDF宽度。** 本项目参数约定 α=r²，采用各向同性矩匹配近似 `r_eff=(r_base⁴+Var(s_u)+Var(s_v))^(1/4)`，上限1。颜色与基础材质粗糙度LOD保留；删除原函数中不再使用的重复法线计算。补偿量来自同一程序化表面的样本，没有随距离人为添加一档粗糙度。

**环境反射实际按粗糙度积分。** 每个相机子样本作8次确定性GGX角度求积，常规两个子样本合计16个方向。按该NDF取微面法线，再追踪真实场景、遮挡、二次水面反射/折射，使用Fresnel和Smith权重。没有随机帧种子或历史混合。瓷砖反射关闭旧空间滤波（guide sigma=0），因此模糊来自真实方向积分，不来自另加图像模糊。水面分支原有滤波保持。

这采用法线分布滤波的思路；参考 [Filtering Distributions of Normals for Shading Antialiasing](https://research.nvidia.com/publication/2016-06_filtering-distributions-normals-shading-antialiasing) 与其 [论文](https://research.nvidia.com/sites/default/files/pubs/2016-06_Filtering-Distributions-of/NDFFiltering.pdf)。本实现是有限样本、各向同性GGX核心宽度近似，**不是声称无界GGX分布具有有限二阶矩**，也不是完整LEAN协方差纹理链。

## 画面与误差检查

2m近景仍能看见瓷砖与倒角造成的非均匀反光；5–10m采光口倒影变为较宽、较柔的反射区域，没有在5m突然变成整齐镜面。固定各距离截图并与离线64角度样本作同机位对照。最终16方向方案与64方向参考的8位最终图误差列在 summary.json；平均绝对差为0.234–0.334个8位等级，p99为2级；8方向方案为0.332–0.505级、p99为3级。这衡量最终画面误差，不能冒充反射项自身的相对误差。参考本身仍不是无偏无限采样真值。

第一人称实际按S后退，从墙前2m到约11.5m，实时水波、身体、正常曝光均开启；两段录像分别记录新旧版本。逐秒解码检查反射随视点移动，没有看到旧版在3–5m变成干净镜面的转换。动态分辨率开着，录像中新版主要为1104×712，旧版随视角为1008×656至1280×832；公平图像比较使用固定1280×832截图，不用不同内部尺寸的录像帧做像素差。

## 折扣与未做到

- 足迹只有四点积分，近似成轴对齐覆盖范围；极窄倒角、大掠射角下的完整面积积分未解析，可能遗漏局部高频方差。只匹配各向同性宽度，没有保存完整各向异性协方差。
- 16个方向是有限求积；虽不使用随机采样或帧历史，仍可能存在有限样本的角度误差。没有声称镜面分布与遮蔽完全收敛。
- 基础颜色/粗糙度LOD及次级材质的面积近似保留，原有粗糙环境小照度项未升级成无限次镜面互反射。
- 固定1280×832的所有场景≥30fps未做到保证；最终正常运行方式借助原动态分辨率达标，分辨率代价明确列出。
