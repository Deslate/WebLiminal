# v1.35：ESC 真正暂停 GPU 渲染

本轮基于 main `ee234dc`（v1.33）；未合入 v1.34 候选。开始时仅用户的 BRIEF.md 修改和 .flops/ 未跟踪目录，均保留且不纳入提交。没有改水波、材质、光传输或渲染质量。

## 实现

查过全 src：没有 Escape 绑定，也没有 pointer lock；WASD / 方向键、Shift、V、M 和拖动保留。ESC 忽略 repeat，切换统一暂停状态。取消待执行帧计时器，暂停时不安排 RAF 或 16ms 轮询；已提交的 GPU 帧允许完成，不再开始下一帧。AudioContext suspend、CSS animation-play-state 同步暂停，输入状态清空，提示 ESC 恢复。

保留 GPU 资源和最后呈现帧，不重建波场；暂停中的窗口 resize 延后到恢复。恢复重置墙钟参考、排除暂停间隔的 FPS 样本，首帧 dt=0，随后正常演化。tickRunning 和唯一计时器防止快速切换时产生多个循环。页面隐藏也取消调度，重新可见时恢复时钟；不会解除用户按 ESC 设置的暂停。原诊断 pause/configure/replay 接口复用这一调度控制。

## 环境及硬件占用

2026-09-28，Apple M3 Max，Chrome 153 headless，WebGPU Metal，画布及内部渲染均 1280×832。发现 Flops 内嵌浏览器另开了一个本项目页面，使用项目自身 pause() 暂停它后重测；未关闭其他用户页面或进程。最终仅一个测试实例运行，没有并行录像或 GPU 实验。测试结束关闭测试实例，原桌面项目页保持暂停，可按 ESC 恢复。

通过 macOS AGX 驱动 `ioreg -r -c AGXAccelerator -l` 的 Device Utilization % 每秒采样。这是整机 GPU 占用，不冒充进程独占测量。暂停先等最后帧完成，再给硬件统计 2 秒更新时间。零提交由 GPUQueue.submit 包装计数独立验证。

| 状态 | 样本数 | GPU 平均 | GPU 中位数 | 范围 |
|---|---:|---:|---:|---:|
| 正常运行 | 10 | 85.90% | 86% | 85–87% |
| ESC 暂停 | 15 | 0.73% | 0% | 0–4% |
| ESC 恢复 | 10 | 86.50% | 86% | 85–93% |
| 关闭测试页面 | 10 | 1.30% | 0.5% | 0–6% |

暂停较运行平均下降 85.17 个百分点（99.15%），与关闭页面处于同一空闲水平。暂停区间新增 GPU 提交 **0**，待调度帧 **无**，完成帧数 **不变**，音频为 suspended。保留显存是为了恢复场景，不表示仍在计算。原始 closedBefore 第一条 90% 是刚暂停另一项目实例后的统计滞后，未删去；关闭页面的主要对照采用完整 closedAfter 段。

模拟时间暂停前后、恢复第 0 帧均为 **12.496300s**。暂停期间保存图完全相同，恢复第 0 帧与暂停图的 PNG 字节及所有像素一致（MAE=0，最大差=0）。后续五帧时间依次为 12.535100、12.569900、12.604400、12.638700、12.673000s；反射随原水波连续演化，没有追赶暂停期间时间或重置水波。逐帧 PNG 导出本身增加耗时，这六帧仅用于连续性，不用于性能。
