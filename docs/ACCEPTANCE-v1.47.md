# v1.47 — 恢复背景波物理时间，诊断并提高动态漫反射采样

## 实现与范围

场景的 `waveSpeed` 从 0.10 恢复到 1.0。原有限水深重力—毛细波算子 `G(L)=sqrt(L)tanh(H sqrt(L))` 未改，整个背景波不再被拖慢十倍。各波长继续由自身的离散色散关系演化。保留整个湿域的带限随机压力、耗散、空间网格、波幅、身体及离散脚步；未添加涟漪贴图或额外光效。

背景积分从 120 Hz 改为 60 Hz，物理时钟仍为 1.0。全支持深度的数值稳定性测试通过；时间积分附加模态频率误差小于 1%。这不是把播放时间放慢；每真实秒推进 60 个 1/60 秒物理步。现有 3.125cm 网格的空间误差仍在，8cm 波长约 13.5% 的误差没有在本轮解决。

动态漫反射从每探针 32 个方向提高到 128 个方向，仍为真实几何可见性、Fresnel/Snell、吸收和材料权重。没有扩大照明滤波核，也没有压低对比度。为避免串行加密把默认机位降到约 12fps：

- 改为按探针连续存储传输链，每 32 个 GPU 线程共同积分一个探针；4 次当前时间漫反射传播保留。
- 每链从 32 字节压为 16 字节；索引仍为完整 u32，RGB 权重存为 f16。128 方向链接缓冲约 358MB，旧 32 方向约 179MB，4 倍方向只增加一倍链接存储。
- 128 方向串行/并行同刻截图逐像素一致。压缩权重相对全 f32 权重的检查：最大通道差 1/255，平均 0.0000488/255，变化像素 0.0195%。这是一个场景夹具的实测，不宣称所有场景逐位相等。

之前未合入的天花板 64 方向釉面候选没有继续叠加：恢复已提交主线的 16 方向，候选原样保存于证据 `current/ceiling-candidate.patch`。这轮的云状闪动不能用那项釉面候选解释。

动态分辨率改为观察最近 12 帧，更快响应超预算的转向，恢复分辨率则保留迟滞。仍然是原有动态分辨率机制；下面必须同时报告实际内部尺寸。

## Benchmark 与性能

命令：`PYTHON=/opt/homebrew/bin/python3 EVIDENCE_DIR=../workroom-v1.47-evidence/benchmark npm run benchmark`。

固定原 76 秒路线、尺寸、阈值，增加同样快波场下的 32 方向 `low-transfer` 对照。`dense-transfer` 现在为 256 方向参考；不得把不同方向数都叫作旧版的 64 方向参考。所有控制都使用同一快波场，不把真实时间变化和积分误差混在一起。

新版本重复重放 607,027,200 个亮度值完全一致，最大差 0。完整 Benchmark 的同区域对比：暗墙/天花板 100ms 块差分 p99 从 0.01293 到 0.01109；第一道门洞从 0.01170 到 0.01305。暗墙大像素变化最大值 0.12157→0.10980；超过 0.10 的样本均为 6，超过 0.08 的样本 46→107。因此不能将“墙面不再爆闪”写成完全通过。

关闭动态漫反射后，大像素变化样本仍有 106（正常版本 107）；关闭釉面后有 123。残余大跳变不是靠继续堆漫反射方向数就能消除，直接水光传输仍需更深入的采样/收敛诊断。这里没有把所有真实水光都判成错误，也没有压平该路径来通过验收。

同一快波场下，32→128 方向使暗墙/天花板差分 p99 从 0.0218137 降到 0.0110907（下降 49.16%），最大异常连通块从 115 降到 13 个 8px 块。256 方向参考为 0.008701，仍存在有限方向积分误差。门洞深处 p99 为 0.00085784，没有孤立大跳变；第一道门洞、暗墙与近砖缝仍触发 REVIEW。
