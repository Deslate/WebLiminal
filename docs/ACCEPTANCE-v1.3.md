# v1.3 验收记录

2026-09-26，Apple M3 Max / Metal，Chrome 153.0.8010.53，headless WebGPU。以 BRIEF 最后六条为准。开发服务器保留在 http://127.0.0.1:4173/ 。完整证据在 `/Users/steven/Projects/workroom-v1.3-evidence/`，图片与视频不进入源码仓库。

## 六条结论

1. **停止后细化：通过本机一秒预算，仍是有限样本近似。** 质量权重在 0.8 秒到 1；12 秒动态序列里的两次停车，在 +1 秒时两张可见波面缓存均为 128 批（每张 16777216 条光子路径）。同机位静止图相对 256 批参考的全图亮度 RMSE 从 2.312 降到 0.796 个 8 位色阶，下降 65.6%；暗墙从 1.348 降到 0.757，下降 43.8%。不是通过曝光变化制造提升。
2. **移动保持干净及 ≥30fps：在实测路线通过。** 构建版行走 58.51fps，开发版 59.66fps；原基准 59.0fps。构建版比基准低 0.49fps，不能宣称逐帧完全一样快；两次测量区间接近原基准。360 帧全部运行孤立亮点检测，最大计数 0。目视检查的帧未见随机采样点、闪屏或拖影。不是对任意设备和视角的普遍证明。
3. **平滑过渡：实测通过。** 等相位、等样本预算的 30 张停止过程图中，相邻帧全图平均绝对亮度变化最大 0.0567/255。真实动态序列另覆盖两次停走，水面正常推进，未看到突然换档；没有重投影或相机历史缓冲。
4. **不自然暗边：修复了明确的面积归一化错误。** CSG 门洞不再作为零照度墙面进入滤波分母；覆盖率回归测试对四座拱门的两侧逐一比较解析接收面积，误差 <0.025m²。反弹上限 7→12，补回更多真实间接路径。保留正常的遮挡阴影，没有加 AO 或虚构环境补光；不宣称所有深处都应该变亮。
5. **空间分辨率与天光积分：通过。** 主要照明格从 8.3cm 提高到 4.17cm；静止天窗积分从 4 点提高到 64 点，每点有几何可见性射线。静止细核约 16.7cm 支持半径，仍有有限宽核偏差；移动保留宽核和四点近似。
6. **不靠糊、拖影或长曝光：通过实现与画面对照。** 无最终画面模糊、相机历史累积、运动模糊或曝光切换；移动与静止均保留 2×2 子像素和完整程序砖缝材质。细化发生于世界光照，水面、折射每帧重新算。

## 第二组证据：运动、停走与真实帧率

`final/motion-and-settle-12s.webm`：1512×982、360 帧、30fps、12 秒。0–4 秒向前行走并转头，4–6 秒停车，6–9 秒横移转头，9–12 秒停车。水和焦散全程演化，正常胶片颗粒开启。原始无损 PNG 在 `final/sequence/`；WebM 用 MJPEG 中间管道和 VP8 编码，细节验收应以 PNG 为准。

影片是连续时间步调用**生产渲染器**所得的等价连续帧序列，不是屏幕实时录制，不用它测运行帧率。`capture.json` 记录每帧相机、波面时间、质量权重、缓存波面时间和样本批数；两次停车 +1 秒为第 150 / 300 帧，两张可见缓存都已达到 128 批；全序列缓存逾期 0。

所有 360 帧均做数值检测。启发式定义：中心亮度 ≥75、8 邻域均值 <50、中心高于所有邻点至少 25 色阶；最大孤立亮点计数 0。该检测只覆盖孤立亮点，不能证明没有所有类型的闪烁。

目视检查了 00、03、06、09、11、12、15、18、21、24、25、29 共 12 张顺序拼版（144 帧），以及入口、拱门、暗部原尺寸对照和解码后的第 5 秒影片帧，重点看暗墙、停走边界、砖缝和水反射；未见随机火花或跳档。没有谎称逐张原尺寸观看过全部 360 帧。

独立性能测试不截图、不编码、不同时运行其他 GPU 验证，统计 `queue.onSubmittedWorkDone()` 后的完成帧。窗口 1512×982，内部 **1280×832 全程未降低**：

| 测试 | 首帧 | 静止平均 | 行走平均 | 静止 / 行走最低整秒 | 静止 / 行走 p95 |
|---|---:|---:|---:|---:|---:|
| 开发版 round-6 | 670.4ms | 50.79fps | 59.66fps | 49.47 / 59.17fps | 23.2 / 18.6ms |
| 构建版 final/performance | 691.7ms | 50.54fps | 58.51fps | 49.58 / 58.40fps | 23.5 / 19.4ms |

构建版稳定段最大帧时 33.8ms，行走 21.8ms，>50ms 帧均为 0；WebGPU 错误 0，外部网络请求 0，缓存逾期 0。静止档从旧基准 58.8fps 降到约 50.5fps，这是追加光子换取更高质量的明确开销，不隐瞒为“性能完全不变”。

## 回归与迭代记录

- `npm test`：7 项通过，包含碰撞、4.2cm 网格和拱门真实接收面积。
- `npm run build`：通过，零位图资源校验通过。
- `npm run verify`：开发版及 `/poolrooms/` 构建路径通过。
- v1.3 连续帧与同机位控制图：通过；参考图及分析结果保留。
- `npm run proof`：水位、天窗、波幅改变后的光传输审计通过，恢复参数后的图片哈希一致。CPU 水波模型已同步到 v1.2/v1.3 十波模型。原状最大 Snell 残差约 3.99e-7，水面求交高度残差 9.95e-6m。
- 早期 round-1 出现降分辨率和较慢帧时，round-2 出现 bind-group 错误，均被否决；不能用它们作成功证据。大核改为可分离解算、预计算接收覆盖率并删除重复求交后恢复性能。
- 16/32/64 批细核暗部误差偏大，因此最终静止预算提高到 128 批。32/64 版证据是中间结果，最终以 `final/` 为准。

## 折扣与未覆盖

第 1、5 条采用有限预算的世界空间照明细化，未恢复完整无偏相机路径追踪：固定密度核、0.4 秒光照插值、有限天光求积、第一处水界面分裂和粗糙釉面间接近似仍在；极细焦散和深暗区的间接光不等于无限样本结果。没有用糊或拖影来回避这些限制。

只在这台 Mac、这个 Chrome 版本、这个窗口和上述路线验证；未穷尽极端掠射、连续高速甩头、全部深暗角落、其他显卡和浏览器。35 秒后的演出变光没有纳入 12 秒连续帧噪声判断。更完整的物理限制见 [PHYSICS.md](PHYSICS.md)。
