# v1.21：干净池底与阳光聚焦

证据根目录：`/Users/steven/Projects/workroom-v1.21-evidence/`。本轮从 `c1fb6ca` 出发，仅修改池底表面/传输材质、共享水波的默认幅度参数、当前水光子的重建与等价采样计算。墙面材质函数逐字保持原样；曝光、色调映射、太阳辐照度、相机、波动方程和扰动算法均未改。没有运行时位图资源。

## 亲眼确认与诊断

先用 `scripts/capture-v121.mjs` 拍 `before/sun.png`、`before/sunNear.png`、`before/dark.png`，再看清洁材质的 `clean/` 对照。阳光区原来确实是柔和、浅淡的明暗起伏，暗处存在材质斑驳。旧池底仍使用 `porcelainFields/porcelainColor` 的污渍、矿物沉积、水线和色斑；清掉这些后，阳光区仍缺乏清楚亮带，因此不能把问题归结为材质。

`diagnosis/` 保存原参数下的原始光照/波场与取消额外核的实验：简单取消池底滤波会显露采样格，并不能补出强聚焦。原幅度参数 0.052、42cm 水深下，波面曲率和折射距离不足以让大部分光线显著聚焦。额外三点三角核又摊宽了较细的阳光结构。诊断不支持“只加亮度”或“只去模糊”。

## 实际修改

- 池底釉面基色固定为线性 RGB `(0.445, 0.60, 0.52)`。去掉污渍、水垢、斑驳、破损暗色与脏缝遮罩；主射线、折射/次级射线和光子 BRDF 使用同一干净底色。保留真实接缝凹槽、倒角、高低差、世界坐标微法线与釉面反射。
- **默认波幅参数 0.052 → 0.12。** 这是对真实模拟初始状态和持续压力源的幅度标定，不是给池底另画光纹，也不是仅放大光子法线。相机求交、反射、折射、墙面与池底光子都读取同一逐帧演化的波场。副作用是水面折射与墙面波光也更明显，不能声称它们的动态外观完全未变。未新增短波源、未改变传播速度/耗散、未冻结相位。
- 池底太阳光子单独累计；照到墙面的太阳光子仍走原核。池底太阳分量使用原有有限太阳圆盘、双线性光子落点和双线性相机重建，**移除额外三点三角滤波**。漫天光保持 v1.20 的核与 4,194,304 路径/帧，不以降采样换速度。分量最终在同一个世界光照场相加，再进入原有间接传播和材质着色。
- 太阳从 384² → 768²，即 147,456 → 589,824 路径/帧，以支持更强聚焦及更窄重建。额外高精度太阳通量存储约 41.3MiB。Snell、Fresnel、介质吸收、接收面积归一化、结构遮挡全部沿用。没有焦散亮度乘数，没有曝光调整。
- Sobol 采样复用每组的高位，只对低位作二进制进位更新；样本逐位不变。新增测试比较 32/128 样本组的原始/增量生成。另测过高位原子加法条件化，短测仅约 2% 差别，不把它当可靠收益，因此没有并入运行时代码。

## 物理量与画面对照

`physical/`：同机位 `(3.5,1.5,-1)`，俯角 -1.45，body=false，重置后真实积分到 3s，曝光0.85。原始光子亮度统计取 2m×2m 固定世界区域，不含材质和色调映射：

|---|---:|---:|---:|
| 原波幅0.052 | 10.8085 | 0.1551 | 15.6392 |
| 新波幅0.12，水深0.42m | 10.7763 | 0.6295 | 41.7285 |

`physical/reference.png/json` 使用4倍天光路径，阳光仍为768²，不是无限采样参考。`physical/aperture-*.png` 和 `aperture-integral.json` 记录开口尺寸响应；中心区域仍在直射光束内时不能仅凭其均值判断开口有无生效，应检查整个池底受光面积和总入射通量。宽长各减半，面积降至1/4时，池底总入射光能260.4109 → 66.2738（25.45%），辐照度大于2的受光面积23.4110 → 6.1146m²。

## 折扣

1. 池底光照单元仍为2.083cm，毫米级焦散丝线没有解析出来；很近的高对比亮带边缘能看到一定离散阶梯/软化。没有用整体模糊掩盖，也不能称光学无限分辨率。
2. 暗处没有直接阳光时仍呈弱而宽的漫天光/间接光变化。没有伪造暗处强日照亮丝；大幅提亮的诊断图仍可见不规则光照起伏及8位量化。
3. 帧率没有恢复历史基准，具体下降见上表；只测了这台机器。
4. 原有身体等效压力、有限间接光、离散波场与边界等近似仍存在，见PHYSICS历史章节。这轮没有借机重做它们。
