# v1.53：照明能量分账

本轮保留当前版本，未回退、未 push。用户的 BRIEF.md 改动、.flops 和既有 v1.46 脚本未纳入提交。

## 已确认的错误与修改

1. 平水面基准的太阳采样域与实时采样域不同：初始化时缺少波高包络，同时将振幅清零还改变了开口投影的采样范围。因此完全平水面也得到非零的漫反射增量。先初始化包络，改用独立的 `sampling.w` 仅切换平水面几何，保持两边同一采样域。平面测试中增量最小值、最大值、积分均严格为零；此前全域积分为 0.406976，天花板为 0.129682。
2. 主相机真实 GGX 反射与旧 `photons * coat * .08` 环境反射近似重叠。主相机已有反射续追时不再加这个近似；无续追的次级着色保留原近似。没有调权重补偿，没有新增遮罩或模糊。
