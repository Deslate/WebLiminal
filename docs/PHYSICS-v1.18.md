# v1.18：世界坐标瓷砖表面

## 先看画面，再查代码

先保存、观看两个暗处池底区域（x3/z-6 与 x4/z6）和亮处（x3/z1）的六张原始截图，再加普通站立高度的暗处/后室广角。默认显示下暗处非常暗；另生成明确标注的 display RGB ×5 图用于诊断，原始图未覆盖。

亲眼看到的是：砖面缺少细节，暗处有厘米至分米级的柔软暗团。但在选到的机位，**未能复现“每一块砖同位置、完全同形”的严格症状**。运行时把相机材质替换成恒定颜色后，大块暗团仍在，说明至少这些区域的大块明暗来自光照，不能全部说成污渍。诊断只覆盖所选位置，不否定用户其它位置的观察，也不能声称已经找到用户截图中每个斑点的唯一根因。

确认的材质缺口：透过水的池底走 `filteredMaterial`，旧版这里只有逐砖均匀颜色和深色缝，近材质里的污渍、沉积没有进入该分支。原有细节主要使用展开 UV 加逐砖 seed，并非简单 `fract(uv)` 复制；边缘矿物沉积仍乘相同的缝距轮廓。v1.18 删除这套逐砖重置的表面细节定义。

## 具体修改

- 新增固定在三维世界米制坐标的整数散列值场，旋转采样格、五次插值，尺度不用 250mm 模数的整数倍，不使用 `fract(tileUV)`、砖心、砖 ID 或逐砖 seed 生成污渍。
- 厘米尺度污斑、分米尺度积垢覆盖与较慢的色调变化共享 `porcelainFields` / `porcelainColor`。水渍、矿物浅色沉积、不均匀深色污渍保留；没有用“全干净”解决重复。
- 主视线、透水/反射简化材质、光子和间接传输的反照率都调用同一世界坐标颜色。避免相机看见脏砖而反弹仍当成旧的干净材质。
- 磨损、微颗粒、釉面微起伏同样从 `h.p` 生成。几何缝距仅用于“磨损只能发生在砖边”的物理位置限制，其强度由不重复世界场控制，不再给每砖乘同一个暗边沉积环。
- 保留实际凹缝、倒角、施工高度误差及拱内排砖。砖几何当然仍有规则模数；表面污渍不随每块砖重置。水位线仍按真实世界高度计算。
- 没有改变波场、时间轴、相机采样数、反射重建或图像历史，没有引入位图资源。光子数 sun147456 + sky524288、四轮间接传播、1280×832 测量分辨率、胶片颗粒 .004 保持。

## 边界与折扣

1. 缺少用户截图的精确机位，本轮自行选两个暗区并提供相同机位对照；不能声称重现了未见到的截图区域。第 3 条“任何地方任何角度绝无可辨重复”不能通过有限图片证明。
2. 暗处依旧遵循实际曝光和光照，污渍不会自行发光。为便于检查提供统一 ×5 显示增益附图，**这不是游戏亮度改变，也不是正常曝光证据的替代**。
3. 二次射线仍使用过滤后的釉面法线与简化缝材质，没有增加完整水下微凹槽几何追踪。高倍图能看到原有砖缝边缘锯齿；本轮没有宣称修好了所有抗锯齿问题。
4. 世界坐标场在测试房间内无重复瓦片；它仍是程序化统计材质，不是化学沉积/磨损物理模拟。近景风格和污渍强度由有限参数控制。
5. 保留 v1.17 光照精度/开口改动，其独立发现及未完成验收范围见 [v1.17 记录](PHYSICS-v1.17.md)。
