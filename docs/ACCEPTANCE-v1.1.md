# v1.1 移动噪声验收

日期 2026-09-26。本版以 BRIEF 最后的 v1.1 为最高优先级。结论：在下面实际检查的移动序列中，未发现肉眼可见的随机采样斑点、孤立萤火虫或历史拖影；停止不再等待收敛。**该结论限于实测场景，不宣称穷尽所有速度、位置、设备与显示条件。** [v1 历史记录](ACCEPTANCE-v1.md)中的旧帧率与收敛模型不适用于本版。

## 解决方式

相机每帧用固定四子样本，水面同时算反射与折射，取消随机路径分支、随机景深、粒子状胶片颗粒与屏幕历史混合。世界空间光子照明在首帧前完成 48×131072 条路径，移动不清空。水面使用固定相位的六个重力波；波面与缓存一致。接缝按像素足迹积分，高频材质细节仅在小于像素时滤除。不对整图做降噪模糊。主要照明格约 8.3 cm，照明核比 v1 更宽，因此细焦散变软，这是明确的照明质量取舍。

波面求交增加受区间保护的 Newton 与二分回退，消除原先求交不收敛造成的水面漏点。完整方法和物理近似见 [PHYSICS.md](PHYSICS.md)。

## 移动画面的实际检查

全部证据在 **`/Users/steven/Projects/workroom-v1.1-evidence/`**，不进入源代码仓库。

1. `round-1/`：第一次确定性相机画面，仍看到砖缝欠采样和波面漏交形成的点，未作为合格结果。
2. `round-2/`：修正求交与材质覆盖率，增加固定四样本；随后删除共享波面中的亚像素毛细波并提高内部像素数。
3. `motion/`：五个持续移动场景，各 12 张原始 PNG，共 **60 张移动图**；每个场景再保存 stop-0、stop-1s、stop-2s，共 15 张停止图。相机在浏览器 RAF 中持续运动，截图时不停止。用同一物理时刻关闭 34.6 秒脚本光照事件，避免把有意变光算作噪声。隐藏文字 UI，不做图片修图。
4. `consecutive/`：额外 **32 张相邻浏览器合成帧**，CDP `Page.startScreencast`、PNG、`everyNthFrame=1`，逐帧立即确认。16 张边走边转，16 张暗部四倍曝光压力图。平均抓取间隔 **34.64 ms / 24.04 ms**。没有主动隔帧，但浏览器抓取可能施加背压，不能证明覆盖每一个 GPU 提交或真实屏幕刷新。

已按顺序查看所有移动图的 2×2 原像素拼版，并单独打开初始机位、暗房及提高曝光暗房的完整图检查。检查重点：整片墙的随机斑点、暗部孤立亮点、接缝连续性、反射轮廓、停止后是否跳变/糊掉。没有发现上述随机噪声或拖影；砖缝和反射后的池底网格仍清楚。光照较 v1 平，焦散更宽，不把这种差异冒充照片级提升。

## 尚未覆盖与取舍

- 没有穷举全关卡每个相机位置、任意加速度、无限快旋转、贴墙极端掠射与所有水位/波幅组合；也未做数小时连续运行。
- 本次移动图检查固定脚本光照时间，**没有逐帧检查 34.6–43 秒的异常变光过程**。这是未覆盖项，不能据这些图宣称所有阶段无闪烁。
- 未检查窗口拖拽缩放、跨屏切换、低性能设备自动降分辨率时的画质变化；未实测 Safari、Firefox、其他 GPU、4K/超宽屏或不同浏览器缩放。
- 使用 headless 硬件 GPU，未把结果冒充前台显示器上的主观实时观看。截图/合成帧检查能抓图像问题，不能覆盖显示器刷新与合成器之外的问题。
- **水面相位固定**，取消高频毛细波、随机景深、随机间接釉面反射与颗粒。相机不做照片级停下渐进提升；选择同一条稳定渲染路径，避免切档。
- 光子缓存有偏且较粗，阴影天空四点求积、多次水界面及雾有近似。细焦散、釉面层次和真实感有折扣。
- 零交互自动有声仍受浏览器策略限制；首个 GPU 帧之前仍只有底色/开场文字，没有回引旧 JPEG 占位。
