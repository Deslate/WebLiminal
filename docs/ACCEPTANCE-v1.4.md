## 七条结果

| 要求 | 本次结果及边界 |
|---|---|
| 1. 接缝真凹陷 | 近景相机实际与圆角高度场求交，接缝床后退 4mm，砖面另有 0.1–1.9mm 中心高度与倾斜。32 点局部光线遮挡。照片里能看到宽度、圆角、侧向遮挡与缝内阴影。全局光子和二次射线仍用宏观几何，极端掠射有回退。 |
| 2. 釉面微起伏 | 两个尺度的稳定世界坐标微法线改变反射方向，光斑被打碎。是微法线近似，没有对微米级橘皮逐一建几何。 |
| 3. 逐砖独立 | 尺寸、旋转、中心偏移、离墙高度、倾斜、颜色、粗糙度、倒角及缺损各有稳定种子。安装误差的尺度是毫米，不是随机把整面墙扭曲。 |
| 4. 有层次的房间反射 | 近景釉面射线实际命中墙、拱门、柱体和水面，结合菲涅耳与粗糙锥方向。斜视照片能看到房间倒影。只追一层釉面反射，四方向积分的高反差轮廓仍可能有分层；不是完整多层无偏光追。 |
| 5. 积垢和水垢 | 缝内积垢、沿缝矿物沉积、砖面水渍与缺损均程序生成，改变颜色和粗糙度。阳光直照的白砖上细节较轻，不以涂黑全砖制造“细节”。 |
| 6. 30cm 与不重复 | 保存四个距离墙/柱面 30cm 的机位。没有位图平铺或重复图案索引；规则施工网格仍然存在。不能承诺任意掠射、任意放大下都真假难辨，高度场侧面和有限反射积分仍是限制。 |
| 7. 白柱与锯齿 | 白柱采用相同砖材质。四子像素基础上，高反差处补到八个空间样本。最后一轮还修正了接缝阴影检查点太稀造成的砖角阶梯：8 点改为 32 点；高度场求交上限 64→128。保留放大前后对照，不宣称有限像素在任意倍率下都没有阶梯。 |

上述改动全部由世界坐标驱动。`npm run build` 的资源验证确认源代码无位图、传输 shader 不读取图像纹理。没有加入画面模糊或相机历史累积。

## 性能

独立测量 GPU `queue.onSubmittedWorkDone()` 完成后的帧间隔，不用 RAF 数量，不同时录像或运行另一个 GPU 测试。窗口 1512×982；最终构建测试、贴墙测试和最终录像均保持 **1280×832** 内部分辨率。

| 最终测试 | 平均 fps | 最低整秒 fps | p95 / 最大帧时 |
|---|---:|---:|---:|
| 构建版默认机位静止 | 58.37 | 57.29 | 20.4 / 29.0ms |
| 构建版行走 | 59.34 | 59.07 | 18.5 / 19.9ms |
| 开发版 30cm 贴墙静止 | 59.51 | 59.61 | 18.8 / 23.5ms |
| 开发版贴墙横移、转头 | 52.64 | 51.85 | 20.5 / 21.1ms |

构建版首帧 **347.4ms**，禁用 HTTP 缓存、新浏览器上下文；不是冷重启整台机器的测试。前两项统计 5–17 秒与 20–22 秒区间；贴墙先运行 7 秒、移动再运行 5 秒，各取最近 90 个完成帧。因此贴墙最低整秒只涵盖这段短窗口，不能当成长时间压力测试；整秒子集与全段平均不必同序。GPU/浏览器错误 0，外部资源请求 0。数据在 `final/build-performance/performance-headless.json`、`final/near.json`，仓库汇总为 `docs/v1.4-metrics.json`。

前几轮性能未通过，已如实保留在 round-* 目录。为保帧率，默认每批光子从 131072 降至 **49152（旧预算的 37.5%）**。保留移动 32 批、静止 128 批、4.17cm 主照明格、细核和 64 点天光。不能宣称这与 v1.3 原高预算严格等精度。原提交隔离复测只有静止 17.77fps / 行走 51.88fps，未复现历史的静止 50.54fps；原因尚未确定，记录在 `baseline/`。本次最终成绩独立测量，不用历史数字替代。

## 动态、噪点与光学回归

最终录像：每 100ms 记录一次相机、水时间和光照缓存，共 160 条。16 秒路线中取首末记录，墙钟差 15.9005 秒、水面时间差 15.8995 秒；光照缓存逾期 0，碰撞位置均合法。原记录 `final/recording.json`。录像解码为 488 帧，保存在 `final/video-frames/`。

488 帧全部做孤立亮点启发式检测：中心亮度 ≥75/255、比全部八邻点至少亮 25、邻域均值 <50。排除界面文字区域和前三秒片头后，场景最大计数 **0**。未遮罩的全画面最大计数 22，检测位置落在底部小号界面文字；完整数值与遮罩范围均在 `final/video-analysis.json`，没有把全画面原计数改写成 0。

我查看了最终录像四张总览拼版（约每 0.48 秒一帧）及 `consecutive-12/17/23/30/36` 五张逐帧拼版（60 个连续帧），另看过原尺寸贴墙、反射、柱体照片和砖角放大对照。覆盖靠墙、斜视反射、停止、退回水面和暗拱门；未发现随机采样火花、整屏闪变或历史拖影。没有声称逐张原尺寸人工观看全部 488 帧，数值检测也不能证明所有类型的闪烁都不存在。

另保留 360 帧、12 秒、30Hz 指定时间步的无损回归序列在 `regression/sequence/`，它不作为实时性能证据。孤立亮点最大 0、缓存逾期 0，两次停车 +1 秒均达到质量权重 1、两张可见缓存均为 128 批。`regression/deadline-60hz.json` 还验证了 60Hz 下的同一预算期限与停车细化。

相同机位、相同冻结波相位的受控比较只用于隔离照明质量：相对同版本 256 批有限参考，入口全图亮度 RMSE 从移动的 **2.648** 降至静止 **1.097**（0…255 色阶）；等预算停车过渡的相邻帧平均绝对变化最大 0.0606。参考不是无限样本真值，也不是与旧 v1.3 画质直接比较。`regression/analysis.json`、`reference/` 保存原数据。

光学防伪回归再次完成原状、改水位、改天窗、平波控制和恢复原状；恢复图哈希一致，GPU 光路的 Snell/Fresnel/反射/权重及波面命中通过 CPU 独立校验。`proof/manifest.json` 保存结果。

## 尚未覆盖及打折处

- 未测试所有墙角、所有掠射角、手机和其他 GPU；不能保证所有机器 30fps。
- 近景高度场没有完整瓷砖侧面网格，极端掠射、曲拱局部切平面与二次反射微几何仍是近似。
- 微釉面用法线起伏，一层有限方向反射仍可能留下高反差倒影分层；尚不能称为“30cm 任意位置真假难辨”。
- 全局光子预算减少，上述通过的是本机清洁度和期限，不等于保留了旧版全部细光精度。
- 0.4 秒光照关键帧仍会平滑快速焦散，BRIEF 的 v1.5 尚未实现。水本身与反射没有冻结。
