## 复现与尺度

先在六个池底位置、三个水深 0.15 / 0.42 / 0.85m 拍 18 张原始截图（`scout/`），再看逐砖放大及材料/照明隔离图。选定暗区 **x≈-4m,z≈-6m**。0.85m 水深时蓝青色点列尤其清楚，跨越砖缝排列；它不是每块砖独立复制的污渍模板。默认曝光下暗部较弱，辅助图明确标了 display RGB ×6/×8，原始正常曝光图均保留。

不同网格不能混为一谈：

| 项目 | 世界尺度 |
|---|---:|
| 瓷砖模数 | 250mm |
| 外墙光照接收格 | 41.667mm |
| **当前池底光照接收格** | **20.833mm**（v1.11 已加密到 48/m） |
| 池底间接光探针 | 166.667mm |
| 天光水面发射位置，256×512 | x 54.6875mm / z 52.7344mm |

对池底真实辐照度缓冲做 2m×2m、96×96 格的世界坐标裁剪，范围 x[-5,-3], z[-7,-5]。去均值、Hann 窗后计算二维频谱。默认正常波幅下两个主要斜向点列周期约 **140.7mm、127.8mm**（频率向量 -11/2,9/2 与 7/2,14/2 cycles/m）。这是点列法向周期，不能冒充所有点的严格最近邻距离；2m 窗频率分辨率 0.5 cycles/m，故数值应按约 14.1 / 12.8cm 理解。

可见周期约半块砖，但既不是 250mm 逐砖模板，也不是 41.67 / 20.83mm 接收格的直接边界。与规则瓷砖并置会增强“每砖都在冒点”的观感。

## 材质还是光照：因果证据

1. 相机材质替换成恒定颜色/粗糙度后，**点阵仍在**。`ab/original.png` 与 `ab/constant.png`。独立材质显示没有相同斜向点列。旧版墙面脏斑与这个问题是两回事。
2. 在同一接收缓冲坐标，默认近乎平水控制（waveAmplitude=0.001m；不是宣称完全零波）下，14.1cm 周期的频谱功率为 **72.953**；恒定材质仍为 **72.953**；移除当前水面光传输变成 **0.06692**（下降 **99.908%**）；移除间接传播仍为 **72.951**。见 `ab/contribution-measurements.json`。该功率只用于相同窗口/归一化的 A/B，不是瓦特。
3. 关闭太阳，所选 ROI 的当前水面光辐照度与原状逐值相同；关闭天光，仅留太阳，该 ROI 为零。**在此暗区，点阵来自折射天光。** 不是所有池底光照都只有天光。
4. 只把天光发射网格由 256×512 改成 512×1024，瓷砖、接收格、间接探针完全不变，主周期 **140.7mm→70.4mm**。总平均能量仅从 0.019351 变成 0.019248，图案却随发射格加密。这个实验排除了“瓷砖局部模板”与“接收格直接显露”的主要归因。
5. 改水深/开口，点列投影、对比度与能量发生变化；近乎平水依然有点阵，因此不是自然波场形成的真实聚焦网络。正常波幅下同样有 14.1cm 主周期。64 个开口样本的昂贵参考明显减轻这组粗点列，但还有细格残留；它只用于诊断，没有部署为修复或计入产品帧率。

**根因：** `water-caustics.wgsl` 的规则水面发射格与 `fract(ix*a+iy*b)` 生成的固定开口偏移有空间相关性；每个位置只取 2×2 个开口方向，经过折射投影，在池底形成规则/近规则的采样点列。小足迹接收滤波没有充分积分这些样本之间的空隙。稳定性避免了随机闪烁，但留下了空间采样偏差。v1.18 改材质没有触及这个根因；继续增加污渍不可能修掉它。简单加密也只是移动点阵频率，不能当作根治。

### 随时间的行为

追加同一暗池底机位、0.85m 水深、正常 .052m 波幅，模拟连续推进到 1 / 4 / 8 秒再拍。亲自查看 `time/comparison.jpg`（明确标注显示 RGB ×6）及原图：点列会随水波挪动、变形、变亮变暗，但规则采样结构仍可辨，不是粘在瓷砖上的固定污斑。真实水面光照 ROI 的 t1→t4 / t1→t8 相关系数为 0.573 / 0.493；平均绝对变化为 0.01306 / 0.01374（分别为 t1 平均值的 72.9% / 76.6%）。这是物理时间推进的三次截图，不冒充实时帧率测量或长时不循环证明。

## 性能与限制

Apple M3 Max / Chrome 153 / WebGPU Metal，内部 1280×832，独立 GPU 完成帧；默认 sun147456 + sky524288、四轮间接、胶片颗粒 .004 未降级。首帧 1637.3ms（未清系统 shader 缓存）。

本轮按要求完成墙面回退和点阵定位，**池底点阵仍存在，未修改光照算法去消除**。没有以强模糊、污渍、加预算或冻结水波掩盖它。旧版几何边缘的高倍锯齿/个别单像素亮点仍是已知限制。不同设备、任意机位没有穷举。
