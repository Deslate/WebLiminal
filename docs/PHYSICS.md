# v1.12：非周期调制波面与行走波包

环境水面保留十个不同波长/相速度的载波，但不再是空间均匀的平面正弦叠加。两个世界坐标随机场分别以不同慢速度平移，局部调制每个载波的相位、方向变化与振幅包络。随机场由整数哈希生成，不读取位图、不按帧抽随机数、不设循环时间或平铺坐标。使用五次插值，格子边界的高度、一阶和二阶导数连续；相机与光子使用包含调制链式导数的同一法线。

角色行走经碰撞解算后才计步。约0.48m步程、至少0.4秒间隔，按行走方向交替左右偏移0.10m；转头、原地顶墙、传送、脚底高于水面都不产生扰动。单次脚步向统一波面加入最大12mm的径向色散波包，传播约0.85m/s，带有限空间包络、0.16秒平滑起振、指数衰减及3.4–4.5秒平滑消退。12个波源可同时干涉；过期后置换不会突然截断未消失波。事件来自行走历史，静止不新增，但既有波继续运动。相机向下俯仰范围扩大至约83度，用户能看脚边水面。

所有事件的高度和解析斜率都进入同一wave函数。阳光/天窗光在这个动态界面做Fresnel分支和Snell折射，再与墙和池底几何相交；相机折射与单方向反射也读它。未恢复旧四个固定锥角点反射、未新增水面圆圈贴片。间接光仍传播当前光照与平均水面基线的差，初始化基线时清零脚步项，避免把脚步烘焙进静态背景。

水面求交的保守高度包络每帧根据仍活跃的脚步振幅/衰减计算。阳光采样足迹包含该高度范围，防止极端高波时截漏天窗边缘。相机帧无历史混合、无随机抖动；水面和全部水光同一时间。原有光子数量、接收网格、间接探针、采样和动态分辨率策略不变，新增成本是解析波面求值及最多12个波包。

限制：这是程序化随机调制波谱加解析扰动，不是求解完整流体方程。没有真实破浪、飞沫、岸壁反射回波、粘性流动、角色实体体积排水；波包靠近固体会被几何遮住，但未计算边界反射。采用慢速随机场调制而非完整色散谱积分。细焦散仍受2.083cm接收格和3×3重建核限制；太阳中心方向、四点天窗散射天光、平均水面间接传输等旧近似保留。不能保证无限时长/任意角度完全没有可辨规律或亚像素走样。见[v1.11原理](PHYSICS-v1.11.md)。
