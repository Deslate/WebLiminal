# v1.14：修正波场的短波能量与方向误差

`src/render/wave-simulation.wgsl`在GPU存储高度η和垂直速度v，使用448×864网格覆盖14×27m水域，间距31.25mm，固定1/360s时间步。每个显示帧执行全部需要的子步；停止行走或转头不会冻结模拟。没有从时间直接求值的正弦载波、解析环形波包或循环动画。

离散模型为非线性高度波动方程：

```
η_t = v
v_t = div(g (D+η) grad η)
      - (σ/ρ) div(D grad Laplacian η)
      - γ v + ν Laplacian v + S
```

g=9.81m/s²，σ/ρ=0.000073m³/s²，γ=0.055/s，ν=0.00008m²/s（数值/有效黏性，不是宣称纯水的分子黏度）。相邻单元共享边通量、用辛欧拉积分，刚度随局部水深与当前波高变化，因此各尺度在同一个场中相互调制。水域与静态水深由实际场景实体生成；墙、柱、拱腿和池边台阶使用无通量边界，而非平铺、穿墙传播或周期边界。毛细项先求曲率再求守恒通量，避免边界处直接展开双拉普拉斯产生非守恒误差。

初始化改成随机散布、随机朝向的局部径向位移/速度波包：96个较大的全域波包，加上局部随机占位的小波包。1.2m分桶仅用于查找附近源，每桶独立泊松数量（均值7.2，最多24个；截尾概率约2×10⁻⁷）、全桶内均匀随机中心；不在桶边界插值噪声，径向紧支撑函数在截断处高度与导数连续。大小波包只是一次性初始状态，绝不按时间重新求值来做动画。

环境压力源半径0.10–1.60m，持续时间0.35+0.9×半径秒；半径大于0.5m的源再乘(0.5/r)²，避免大面积、长持续压力积累出超出求交包络的巨浪，调整为中/大尺度占主要能量。后续高度完全由积分得到。伪随机流只在创建压力事件时前进，不按显示帧重抽光学样本，不循环时间，不平铺空间。大小尺度共同改变局部传播刚度，不是三层独立法线。

重力、曲率、压力核、速度耗散统一用九点算子：轴向权重2/3，对角权重1/6。边连接对称；对角连接遇到任一相邻干单元则关闭，不能斜穿柱角。边界显式关闭出界连接，无周期取模。短波耗散发生在状态的速度方程里，频率越高耗散越强；没有更改相机重建核、模糊整幅图像或冻结水。25cm波长的方向相速度误差由四邻域的1.3036%降至0.02677%；12.5cm处仍有0.44545%残余离散误差，并非数学上完全各向同性。

真实碰撞解算后的步程触发脚步压力源（沿用0.48m步程、至少0.4s间隔和左右脚偏移）。0.28秒内平滑施加压力，随后源关闭，既有高度和速度继续传播、干涉、衰减并被固体边界反射。波不会因为事件过期而被删掉，也没有恢复到无脚步图案的捷径。脚步不消耗环境扰动的随机数流，便于严格A/B对照。源槽重用不会删去已经传入场内的能量。

压力源取局部高斯压力的离散负拉普拉斯，采用同一无通量边界，避免把一个连续零积分函数直接截到池边后造成水位漂移。空间核只在源创建时算一次，子步读取核并乘连续的时间包络；缓存的是静态压力作用形状，不是光照关键帧。模拟状态不会从缓存图案重建。

显示时只对不足一个子步的余量做速度外推（≤2.78ms），再生成C1连续Catmull–Rom三次曲面系数。所有相机求交、反射、折射、阳光与天窗光子都读取同一份曲面，并使用该曲面的解析导数。系数预计算只是减少重复读取，相机仍逐帧独立，没有历史混合、随机采样或水面冻结。正常胶片颗粒0.004保留。

对照发现旧天光发射格间距约11cm，与2.083cm池底接收格不匹配，在平稳波场上形成可辨的亮点阵列。单独增加天光空间求积密度，在不增宽接收核的情况下消除这一光学采样形态；没有把它误称为波动方程的问题。光传输预算增加：每帧147456阳光包、524288天空包（天光网格128×256提高到256×512，四方向不变），池底接收格仍为2.083cm、3×3核；其余接收面保留原核，73225个间接探针、每探针64条链、4次传播。水下吸收、Snell/Fresnel、遮挡及同帧墙/池底焦散不变。新增模拟存储约74MiB，包括压力核缓存、状态和曲面系数。原有动态分辨率策略保留，实测尺寸见ACCEPTANCE.md。

## 明确的近似与限制

- 这是非线性重力—表面张力**高度场波动模型**，不是完整三维Navier–Stokes求解器。采用浅水型恢复项，不提供全波数范围精确的深水色散。
- **第2条的毛细细波打了折扣**：31.25mm网格不能解析毫米级毛细波，可靠的最细尺度约需4个网格（约12.5cm）。表面张力参与已解析场的演化，但不能称作真实毫米级毛细细节。未用额外解析法线层伪装这些未解析频率。
- 没有翻卷、破浪、飞沫、湍流、真实人体体积排水；脚步是等效压力作用。水域边界由平均水位生成，不计算动态爬岸/干湿迁移。最短波有网格色散与方向误差。
- 90秒状态测试与本版长镜头检查循环；没有设置回放周期，但有限观测不能证明任意方向、无限时长下绝无可辨规律。
- 最细焦散受原有接收格/核限制，掠射反射和高反差边缘仍可能亚像素走样；不能把孤立像素启发式当作全局无闪烁证明。太阳中心方向、有限天光求积、平均水面静态间接基线等旧近似仍在。

高度场方法参考：[Bridson等，SIGGRAPH Fluid Simulation课程](https://www.cs.ubc.ca/~rbridson/fluidsimulation/2006/)，相关浅水/波动方程章节。上述具体离散、压力源、接口和参数以仓库实现为准。此前实现记录见[PHYSICS-v1.13.md](PHYSICS-v1.13.md)。

有限水深的真实色散关系为ω²=(gk+σk³/ρ)tanh(kD)，见[剑桥课程练习](https://www.damtp.cam.ac.uk/user/hinch/teaching/D24c.pdf)。本版仍用浅水型恢复项，没有冒称已实现该全频关系；解决高频观感靠合理激励谱与状态耗散，而非调慢显示时间。最短网格波不应承载主要可见能量。
