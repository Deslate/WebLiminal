# v1.11：水下池底焦散

池底此前已是sid=3的光子接收面，光路没有遗漏它。实际问题是浅水细波曲率弱，加上24格/米、7格重建核抹去了大部分细节。没有新增池底贴图、程序图案或亮度增益。

仍由同一waterPacket逐帧发射反射/折射两个确定性分支，Fresnel分配能量、Snell计算方向、场景求交决定接收面。天窗与建筑遮挡在入射段和出射段均计算。墙面和池底使用同一波函数、同一秒数、同一能量与面积归一化。相机穿过水面后读取该接收面的实际辐照度，乘材质与回程水下透射；光子入水时已算前程衰减。吸收系数仍为RGB=(0.34,0.075,0.037)/米，因此红光随水深衰减更快。

10个波的方向、波数、相速度不变；增强末四个14–32cm波长的毫米级细波（默认振幅约3.64、2.60、1.77、1.25mm），减小最长波的份额，总振幅上界1.064倍仍在原1.07倍求交包络内。反射、折射、墙光和池底全都读取这一波面，没有仅供池底的假法线。

池底直接接收网格从336×648升到672×1296（2.083cm/格），重建核从7×7降到3×3，仍有双线性光子沉积和接收查询。其它接收面保留7×7稳定重建。分辨率适应于受光面，不是添加第二套光照；有限网格重建仍会限制极细丝状焦散。总光照网格1,805,458格，原为1,152,274格。

间接光探针与直接焦散分辨率解耦：池底每8个细格一个探针，保持6个/米；其它面每4格。总探针仍73,225，64条传输连接、4轮传播不变。阳光384²包、天空128×256×4包均不变。无光子预算削减，无时间插值，无相机历史或新图像去噪；原动态分辨率仍启用。

折扣：焦散并非越浅越锐的单调函数。0.22m尚未充分聚焦，0.42–0.85m更接近部分波的焦面，会更强，深处还存在离焦、叠加及吸收。没有额外套随水深的模糊来强制迎合该描述。太阳仍用中心方向、天窗散射天光仍为四点求积；间接光仍使用平均水面传输加当前光照扰动。没有新增水体体积散射、真实太阳盘积分或完整波动光学。原釉面有限反射重建、掠射角高度场等限制保留，见[v1.10原理](PHYSICS-v1.10.md)。
