# v1.3：运动稳定，停止后细化世界照明

以 BRIEF 最后的 v1.3 为准。v1.1 的静止水面和不再细化照明已经废弃；[旧说明](PHYSICS-v1.1.md)只用于历史对照。

## 光传输与静止细化

相机仍是确定性的 2×2 子像素积分。第一处水界面同时计算 Fresnel 反射与 Snell 折射，保留 Beer–Lambert 吸收和透射辐亮度的介质变换。没有每像素随机分支、屏幕历史累积、重投影、运动模糊或图像降噪。材质仍在读取照明后逐像素求值，因此细化只改变光照，不改变砖缝、相机分辨率或几何边缘。

停止后恢复的是**世界照明的渐进细化**，不是把包含动态水面的旧相机图叠加起来：

- 运动：每个波面时刻 32×131072 = 4194304 条光子路径，较宽密度估计，四点实时天窗求积。
- 停止：后台继续追加到每时刻 128×131072 = 16777216 条路径，读取更细的密度估计及 64 点天窗积分。光子路径上限由 7 次交互提高到 12 次，保留俄罗斯轮盘及其无偏存活权重。
- 质量权重在停止后 0.8 秒内按 smoothstep 从 0 到 1，重新移动时 0.35 秒退回；混合的是同一世界位置、同一光照时刻的两种照度估计。曝光和相机像素数不切档。
- 追加路径只写尚未显示的未来波面缓存，已经在画面中使用的缓存不会半成品更新。时间插值仍连续，记录每个可见缓存实际完成的样本批数。验收序列两次停车后 1 秒检查两张可见缓存是否均达到 128 批。

这是一秒预算内的有偏光子密度估计细化，**不是无限样本的无偏路径追踪收敛**。静止档计算更多，实测帧率允许低于运动档，但仍须 ≥30fps。

## 空间分辨率与暗边修正

主要接收面从 12 格/米提高到 24 格/米，约 **8.3cm → 4.17cm**，其他面由 8 提到 12 格/米。当前场景共有 1152154 个密度单元。粗、细照度使用同一光子通量与物理面积，分别是 13×13、9×9 tent 核；主要面的非零中心支持半径约 25cm / 16.7cm。它们滤的是世界空间的光子密度，不是最终画面。

之前拱门正面的矩形网格覆盖了被 CSG 挖掉的门洞。旧核把洞内没有接收面的单元当成“零照度墙面”，同时计入分母，产生不应有的暗环。现在每格保存四个子点的真实覆盖率，按实际接收面积归一化；门洞面积不再稀释洞口照度。没有添加 AO、环境补光或人工提亮边缘。更多真实反弹也补回了深处原先被路径上限截断的能量，但不把所有真实遮挡阴影抬成灰色。

为控制开销，各批通量先在原子缓冲累加，再在完整批次后解算。二维 tent 核拆成水平和垂直两遍，避免每个光子批次反复做大核滤波。孔洞覆盖率由固定几何预计算，避免在 GPU 滤波中重复求交。相机还去掉了第一次不透明命中的重复求交。

## 天光面积积分

高质量照度来自真实矩形天窗的 **8×8 = 64 点**面积积分，每个点都有解析几何可见性射线、距离平方、入射余弦、发射余弦以及 Schlick 入射透射因子。它在启动或物理配置重置时算到世界网格中，不是预存贴图。运动中的四点面积求积保留；静止平滑过渡到 64 点，减少四点阴影阶梯。

64 点是有限求积，不是天光的解析精确解。网格积分采用几何法线，砖边微法线的入射积分仍是近似；出射涂层项与瓷砖材质逐像素求值。

## 水、焦散与颗粒

v1.2 的十个确定性重力波保留，分成大尺度慢起伏、中尺度波动、小尺度快波纹；相位由连续秒数推进，相机和光子求交使用相同波面。波面不因停走冻结。光子经过真实水界面和墙面反弹，墙顶与水底焦散来自接收通量，无投影波纹图片。

三个缓存轮换：当前时刻、下个时刻、正在构建的未来时刻，间隔 0.4 秒，使用共同随机数并平滑插值。未来缓存的逐帧工作预算随实际时间步调整，30Hz 证据序列也不能拖欠光照更新。光子积分完成才投入显示，不混合不完整结果。

反射保留随法线变化的四方向有限锥积分，折射保留几何细节；胶片颗粒为屏幕程序噪声，在相邻 12Hz 场之间连续插值，最大约半个 8 位色阶、暗处降低四倍。它不是路径采样噪声。

## 仍有的限制

- 有限光子数和有限宽核仍有统计误差与偏差；暗部的细小间接光结构仍不等于完整路径追踪。验收必须报告各区域误差，不能只挑全图平均。
- 0.4 秒光照关键帧会平滑极快的细焦散。水面几何每帧连续推进，这不是冻结水。
- 相机只显式分裂第一处水界面；粗糙釉面间接镜面仍是有界照度近似，不是完整 GGX 多次反射。没有恢复随机景深和体积路径追踪。
- 太阳仍是单方向可见性；34.6 秒异常把天空的间接项也随太阳比例调暗，是演出近似。
- 有限像素和固定四子样本仍可能有亚像素边缘 aliasing；并不声称所有设备、分辨率和任意运动速度都已经验证。

光学回归脚本使用独立 CPU 十波模型核对 GPU 的 Snell、Fresnel、反射方向、通量权重和水面法线；物理参数恢复后的原图必须一致。当前实测与证据见 [ACCEPTANCE.md](ACCEPTANCE.md)。
