# v1.1：稳定相机与运行时光子照明

v1.1 明确把移动干净放在全程路径追踪之前。v1 的随机相机路径与停止收敛模式已移除；[旧模型](PHYSICS-v1.md)只作历史说明。

## 为什么之前一动就有斑点

v1 相机每像素每帧只有一个随机样本，水面只随机选反射或折射，还随机采样面积光、釉面延续、空气散射、透镜与胶片颗粒。移动清空相机累积，光子照明也只保留很短历史。稀有大权重路径在暗处尤其显眼。增加停止后的采样数无法解决移动第一帧的问题。

## 当前相机

每像素使用固定 2×2 子像素求积，各帧独立覆盖写入，没有重投影、历史缓冲混合、随机 jitter 或两态切换。水面求交后同时计算反射和 Snell 折射，并按 Fresnel 权重相加，透射含介质辐亮度变换与 Beer–Lambert 深度吸收。相机不再随机延续 GGX 光路。

太阳使用固定方向的可见性射线；天窗天空使用四点固定面积求积。釉面的太阳高光保留 GGX，粗糙间接镜面项使用有界的照度近似。空气用确定性消光与低强度雾色，不再随机采样单次散射。28 mm 焦距保留，改为针孔相机；旧配置中的焦距以外透镜参数保留兼容字段，但随机景深关闭。ACES、轻微色差与暗角保留，随机胶片颗粒关闭。

## 稳定的世界照明

启动时发射 **48 批 × 131072 = 6291456** 条光子路径，再显示第一张相机帧。光子仍从真实天窗位置进入，经过实际波面、反射/折射、吸收以及最多七次材质反弹；分支重要性权重和接收面积归一化保留。

主要接收面的密度格改为 **12 格/米**（约 8.3 cm），7×7 tent 核估计照度；边缘按实际核权重归一化。空间核会柔化焦散，这是降低照明分辨率的明确取舍。材质在读取照度之后逐像素计算，滤波没有作用于最终图像或砖缝。每批照度估计取平均，缓存就绪后不再逐帧改变；相机走动、旋转、停止不清空或更新它。

波形现在是六个重力波，固定在同一时刻；高频毛细波从共享几何中删除，避免无法稳定采样的亚像素反射边界。缓存与相机一致，不是光斑静止而水面仍偷偷变化。改变水位、波幅、天窗会重新执行全部 48 批。没有任何预存光照图片。

34.6 秒的异常使用平滑的太阳功率变化和照度缓存乘数，天空间接光也跟随该乘数衰减，因此这部分是整体照明近似，不是重新求解各光源的独立贡献。

## 另两个“像噪点”的问题

波面原来的无约束 Newton 迭代可能漏交，造成零散的水面洞。当前使用包围高度区间内的 safeguarded Newton / 二分回退，最大 24 次迭代，通常在高度残差 1e-5 m 时停止。

砖缝使用估计的世界像素足迹积分覆盖率，小于像素的橘皮、细裂纹与磨损逐渐滤除；像素足够时保留。相机固定四样本进一步抑制几何边缘锯齿。不做整图模糊，也不依靠拖长曝光掩盖运动噪声。

## 仍是近似

- 水波不再随时间运动；固定波面仍能产生随视角变化的真实几何反射与折射。
- 相机只分裂第一处水界面，后续直接求交不透明几何；极端掠射、多次穿越波面的路径未完整追踪。
- 固定光子核有偏且更宽；细焦散变软，间接光细节少于 v1 收敛终稿。
- 天空四点求积可能产生稳定的阴影阶梯；不是完整面积光积分。没有随机 DOF、完整粗糙镜面间接传输或体积路径追踪。
- 有限像素数下不能数学保证任意相机速度与任意小几何特征都无 aliasing。当前没有用该限制为明显的采样斑点开脱，实际移动序列必须检查。

`npm run proof` 仍独立校验 GPU 路径的反射、Snell、Fresnel、波面高度与通量权重，并要求恢复物理参数后的图逐像素一致。当前单张相机帧已独立完成，脚本的 `targetSamples` 只是历史兼容名称，表示停止前渲染的帧数；不代表继续收敛的相机 spp。
