# v1.10：洞口内外分面留缝

只改洞口实际边缘的接缝，外墙仍是v1.9普通方砖网格；没有附加砖圈、压条、造型线或新增几何体。内侧`archCourse`、`archAlong`、250mm排程和世界z基准不变。

普通砖缝和新交界缝共用`GROUT_HALF_WIDTH=2.8mm`。以两面展开长度计，交界两侧各退2.8mm，合计5.6mm；倒角肩部与普通缝使用相同的1.2–2.8mm参数，不额外加宽。前/背外墙以到实际洞口曲线的距离截断砖面；内侧以到墙厚两端的距离截断砖面。仅`kind=arch`的这些面参与，普通房间墙角、池底等不增加处理。

交界距离进入原有`tileProfile`，用于高度、法线、材质、主射线高度场求交以及局部光照遮挡。已移除原来的连续45°釉面切边。早期直接沿两面各退4mm会使斜看时对向倒角挡住缝底；最终交界槽底在各基面后1.8mm，按名义砖面高1mm折算，角平分线方向约退4mm。平面普通缝仍退4mm，交叉缝在距洞口2.8–8mm内平滑接入这个转角槽底，梯度同步参与法线计算，避免交汇点出现深度台阶。

这不是只涂深色：独立GPU核验直接执行生产`traceSolid`、`reliefHit`、`tileProfile`及材质函数，斜视中心射线在原几何命中之后约2.5mm才命中槽底，两面采样高度均为-1.8mm、材质为低釉层填缝料。原始数据保存在仓库外`joint-audit.json`。

仍采用局部高度场和局部平面遮挡，并非完整封闭砖体；极端掠射角、两面之间精确的交叉遮挡和次级射线毫米级几何有近似。阳光直射的转角缝对比度可能很低，阴影斜视近照能更清楚看出槽底；没有为了证据额外压暗材质。原有反射锯齿、轮廓亮点不在本版扩展处理。旧版原理见 [v1.9归档](PHYSICS-v1.9.md)。
