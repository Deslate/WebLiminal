# v1.9：删除外墙装饰拱圈

唯一运行时改动在`src/render/common.wgsl`：删除正/背面250mm饰面带的专用模式、径向UV与切割分界。外墙从头到尾使用世界x/y的250mm普通方砖；洞口的原有CSG直接裁掉相交部分。没有新增砖圈、造型线、包边、材料或几何体。

原有毫米级45°切边仍只在洞口实际边缘保留；它不是一圈新砖，也没有加宽。普通墙砖不会再在距离洞口250mm处终止。前后外墙同样处理，其他墙面、照明、水波、相机采样和动态分辨率没有变化。

内侧（圆弧内表面和两侧直线厚度面）继续使用v1.8原有的展开坐标、世界z基准和250mm整模数；拱顶余量落在左右镜像的切割片，最高点是一条缝。`archCourse`、`archAlong`函数保留。v1.8关于外表面300mm楔片坯料、饰面带外边界的说明已经失效，那些构造本版删除。

主射线局部高度场、槽深、倒角和次级几何近似仍沿用旧版。釉面反射锯齿、轮廓孤立亮点没有在本版扩展处理。既有光学原理与近似见 [v1.8归档](PHYSICS-v1.8.md)，本页优先于归档中对外圈的描述。证据和验证见 [ACCEPTANCE.md](ACCEPTANCE.md)。
