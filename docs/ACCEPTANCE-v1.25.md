# v1.25：0.15mm有限水深短波与池底诊断口径

证据目录：`/Users/steven/Projects/workroom-v1.25-evidence/`。池底诊断仅使用实际GPU池底太阳照度缓冲；水面以上画面仅作观感/连续性验收。没有push。

## 实施

新增 `src/render/short-waves.js`，在 `common.wgsl` 的共享 `wave()` 中使用。三个短波模态的波长为80/105/130mm、方向为0.37/2.11/4.28rad，沿用v1.24已验证的0.15mm总幅度参数，每模态振幅0.15/√3mm，新增高度RMS约0.106mm。0.5/1mm实验参数没有进入运行时代码。随waveAmplitude降低而减弱，并以0.15mm封顶；零波幅时短波关闭。

短波使用 `ω²=(9.81k+0.000073k³)tanh(kD)`，而不是短波不适用的浅水近似。默认waveSpeed=0.28，显示频率约1.265/1.094/0.979Hz；使用同一确定性时钟，freeze和waveSpeed=0停止相位演化。每帧CPU计算波数、有限水深频率/相位，GPU只计算共享高度及其精确空间梯度，避免在每条光线内重复算色散。Uniforms从416扩到464B，不新增纹理或光照层。

相机的水面交点、反射/折射、太阳光子和其他使用wave()的路径读取同一曲面。焦散仍通过源光线→Snell折射→池底落点→守恒接收面积记录产生；池底没有附加图案、独立光纹、后处理增益。材质、曝光、太阳源、640²光束预算、2048²接收图、重建足迹、现有长波幅度和步行扰动参数均不变。

**替换范围必须说清：本轮是将已验证的有限水深短波频段合入共享曲面，并未把整套背景/脚步PDE改写为有限水深求解器。** 原有长波、压力源和身体尾迹保持原实现；没有宣称全频段浅水误差均已消除。短波是三个有限水深线性自由模态，不包含它们对池壁的反射/散射或非线性模态耦合；方向数量有限。这些是模型近似，不是完整流体解。`simulation.audit()`的高度网格仍只导出原有状态场，完整光学曲面还包含本模块；审计接口新增shortWaves字段导出实际上传的模态参数，CPU光学校验据此独立重建完整高度/法线，因此不可把基础网格单独当作完整波面。

## v1.23重测：数值没有水面污染，展示口径需要修正

复测源码版本：v1.22=`ca09c32`、v1.23=`8ce969c`、本轮工作代码。历史渲染器和common shader一起从Git读取，避免新版短波混入旧版。相同种子、水深0.42m；reset后以1/30s推进至6s；池底区域x∈[2.5,4.5]、z∈[-2,0]，512²固定世界坐标样点。

读取链路为：`solarTexture`当前帧RGBA16F接收图 → COPY_SRC读回 → RGB转亮度 → 固定世界坐标双线性采样 → 统计。没有读取屏幕PNG，不经过相机反射、池底材质、水体到相机的透射或色调映射。光线从太阳穿过水面的折射和吸收本来就是池底入射光的一部分，保留它们是正确的。

v1.23原报告和脚本本来就使用这条原始接收缓冲链路。本轮重新读取的两份512² float32与旧证据**逐样点完全相同，最大差0**，见 `irradiance/historical-recheck.json`。

因此，“修正前30.13→25.31mm”与“重测30.1348→25.3061mm”只有显示精度区别，**没有需要扣除的水面数值偏差**。原问题是把水面以上的俯视图作为池底诊断展示，混淆了视觉证据与独立光照数据；本轮以缓冲可视化纠正。因此本次修正的是证据分类与标注，而非数值。

本轮对v1.23：梯度结构尺度缩小约24.59%，CV提高约14.48%，P99/P50提高约4.73%，最亮1%能量占比提高0.09484个百分点；区域平均照度仅增加0.000212%。这是池底入射光能的重新分布，不是整体提亮。以上都是**太阳直达照度分量**，不是全部漫反射照明，也不是屏幕图像指标。

梯度尺度定义：`std(E)/sqrt(mean((∂E/∂x)²+(∂E/∂z)²))`。半峰连通区阈值为`median(E)+(max(E)-median(E))/2`，取含全域峰值的连通区并换算圆等效直径。两者都不能直接称作某条真实焦散细丝宽度。本轮仍未达到遍布池底的毫米级强焦散。
